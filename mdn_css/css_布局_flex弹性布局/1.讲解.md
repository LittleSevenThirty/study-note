# 📝 CSS Flexbox 弹性布局速查笔记

> 适用于：快速复习 / 开发查阅 / 面试准备  
> 版本依据：现代浏览器标准（2025年）

---

## 一、Flex 是什么？

- **全称**：Flexible Box（弹性盒子）
- **目的**：提供一种更高效、灵活的方式来对容器内的子元素进行**排列、对齐、分配空间**，尤其适合**响应式布局**。
- **优势**：
  - 轻松实现**垂直居中**
  - 自动适应剩余空间（`flex-grow`）
  - 智能收缩避免溢出（`flex-shrink`）
  - 控制换行与多行对齐（`flex-wrap` + `align-content`）

> ✅ 一旦设为 `display: flex`，子元素的 `float`、`clear`、`vertical-align` **全部失效**！

---

## 二、核心概念：容器 vs 项目

| 角色 | 名称 | 说明 |
|------|------|------|
| 父元素 | **Flex 容器（container）** | 通过 `display: flex` 或 `inline-flex` 声明 |
| 子元素 | **Flex 项目（item）** | 自动成为弹性项目，无需额外设置 |

### 两根轴（关键！方向由 `flex-direction` 决定）

| 轴 | 默认方向 | 说明 |
|----|--------|------|
| **主轴（main axis）** | 水平（从左到右） | 项目**默认沿此轴排列** |
| **交叉轴（cross axis）** | 垂直（从上到下） | 与主轴垂直 |

> ⚠️ 注意：**主轴不一定是水平的！** 如果 `flex-direction: column`，则主轴变为**垂直方向**，交叉轴变为水平。

---

## 三、容器属性（6个）

作用于 **Flex 容器**

### 1. `flex-direction` —— 主轴方向
```css
.box {
  flex-direction: row | row-reverse | column | column-reverse;
}
```
- `row`（默认）：→ 水平，起点在左
- `row-reverse`：← 水平，起点在右
- `column`：↓ 垂直，起点在上
- `column-reverse`：↑ 垂直，起点在下

> 💡 改变 `flex-direction` 会**交换主轴与交叉轴的方向**！

---

### 2. `flex-wrap` —— 是否换行
```css
.box {
  flex-wrap: nowrap | wrap | wrap-reverse;
}
```
- `nowrap`（默认）：所有项目挤在一行（可能溢出）
- `wrap`：换行，**新行在下方**
- `wrap-reverse`：换行，**新行在上方**

> ✅ 多行布局时，`align-content` 才生效！

---

### 3. `flex-flow` —— 简写
```css
.box { flex-flow: <flex-direction> <flex-wrap>; }
/* 例如 */
flex-flow: column wrap;
```

---

### 4. `justify-content` —— **主轴对齐**
控制项目在**主轴上的分布**

```css
justify-content: 
  flex-start |    /* 默认，起点对齐 */
  flex-end |      /* 末尾对齐 */
  center |        /* 居中 */
  space-between | /* 两端对齐，中间等距 */
  space-around |  /* 每个项目两侧等距（边距 = 间隔/2） */
  space-evenly;   /* 所有间距相等（含边缘）*/
```

> 📌 `space-evenly` 是较新属性，但现代浏览器已广泛支持。

---

### 5. `align-items` —— **交叉轴对齐（单行）**
控制**所有项目**在交叉轴上的对齐方式

```css
align-items:
  stretch |       /* 默认，拉伸填满容器（高度未设时）*/
  flex-start |    /* 交叉轴起点对齐 */
  flex-end |      /* 交叉轴终点对齐 */
  center |        /* 交叉轴居中 */
  baseline;       /* 文字基线对齐 */
```

> 🔍 `stretch` 只在项目**未设置高度或 height:auto** 时生效。

---

### 6. `align-content` —— **多行交叉轴对齐**
仅当 `flex-wrap: wrap` 且**存在多行**时生效！

```css
align-content:
  stretch |         /* 默认，行拉伸填满交叉轴 */
  flex-start |
  flex-end |
  center |
  space-between |
  space-around;
```

> ❗ 单行布局时，`align-content` **完全无效**！此时用 `align-items`。

---

## 四、项目属性（6个）

作用于 **Flex 项目（子元素）**

### 1. `order` —— 排列顺序
```css
.item { order: <integer>; } /* 默认 0，越小越靠前 */
```

> ✅ 可用于视觉顺序 ≠ DOM 顺序的场景（如响应式调整）

---

### 2. `flex-grow` —— **放大比例**
```css
.item { flex-grow: <number>; } /* 默认 0 */
```
- `0`：不放大
- `1`：参与瓜分**剩余空间**
- 若 A:2, B:1 → A 分得剩余空间的 2/3，B 得 1/3

> ⚠️ `flex-grow` 分的是 **剩余空间**，不是总宽度！  
> 若项目有内容（如文字），会先占用自身宽度，再分配剩余空间。

---

### 3. `flex-shrink` —— **缩小比例**
```css
.item { flex-shrink: <number>; } /* 默认 1 */
```
- `1`：空间不足时按比例缩小
- `0`：禁止缩小（常用于固定宽度元素）

> ❌ 负值无效

---

### 4. `flex-basis` —— **主轴初始大小**
```css
.item { flex-basis: <length> | auto; } /* 默认 auto */
```
- `auto`：按内容大小
- `0`：忽略内容，从零开始分配（常配合 `flex-grow` 实现精确比例）
- 可设为 `100px`、`50%` 等

> 💡 `flex-basis` 决定了“分配前的基础尺寸”

---

### 5. `flex` —— **推荐使用的简写**
```css
.item {
  flex: none | [ <grow> <shrink>? || <basis> ];
}
```
常用快捷值：
- `flex: 1` → `flex: 1 1 0%`（现代浏览器行为）
- `flex: auto` → `1 1 auto`
- `flex: none` → `0 0 auto`

> ✅ **强烈建议优先使用 `flex` 而非单独写三个属性**，避免浏览器计算歧义。

---

### 6. `align-self` —— **单个项目交叉轴对齐**
覆盖容器的 `align-items`

```css
.item {
  align-self: auto | flex-start | flex-end | center | baseline | stretch;
}
```
- `auto`：继承父容器的 `align-items`

> 🎯 用于某个项目需要特殊对齐（如“只有这个居中”）

## 五、常见误区 & 避坑指南

| 问题 | 正确理解 |
|------|--------|
| “`flex-grow: 2` 的项目宽度是别人的 2 倍？” | ❌ 是**剩余空间**的 2 倍。若内容宽度不同，总宽 ≠ 2 倍 |
| “`justify-content` 是水平对齐？” | ❌ 是**主轴对齐**！若 `flex-direction: column`，它就变成**垂直对齐** |
| “`align-content` 和 `align-items` 有什么区别？” | `align-items`：单行内每个项目的对齐<br>`align-content`：多行之间的对齐（行作为整体） |
| “为什么 `flex: 1` 后元素被文字撑开？” | 因 `flex-basis: auto`（旧行为）。现代浏览器 `flex: 1` 默认 `flex-basis: 0%`，可避免此问题 |
| “`space-around` 两边间距为什么小？” | 因为它是“每个项目两侧等距”，所以边缘间距 = 中间间距的一半 |

---

## 六、速记口诀

> **容器六属性**：  
> 方向（direction）→ 换行（wrap）→ 流（flow）→ 主轴对齐（justify）→ 单行交叉对齐（items）→ 多行交叉对齐（content）  
>   
> **项目六属性**：  
> 顺序（order）→ 放大（grow）→ 缩小（shrink）→ 基础（basis）→ 简写（flex）→ 自我对齐（self）

---

## 七、实用技巧

1. **完美居中**：
   ```css
   .container {
     display: flex;
     justify-content: center;
     align-items: center;
   }
   ```

2. **左侧自适应，右侧固定**：
   ```css
   .left { flex: 1; }
   .right { width: 200px; }
   ```

3. **等高卡片布局**：天然支持！无需额外 hack

4. **响应式换行**：结合 `flex-wrap: wrap` + 媒体查询

---

> 📌 **最后提醒**：Flex 是**一维布局**（主轴方向），复杂二维布局（如网格）请考虑 **CSS Grid**。
