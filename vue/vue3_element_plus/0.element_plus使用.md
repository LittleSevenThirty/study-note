# **element_plus使用**
想要在`vue`项目中成功使用`element_plus`需要完成以下步骤

## **①安装`element_plus`库**
这里使用`npm`下载库到本地，其它下载器可参考官方文档
```powershell
npm install element-plus @element-plus/icons-vue --save
```
* `element-plus`：该库是必须的
* `@element-plus/icons-vue`：该库是因为官方文档中使用了一些自带图标，将其打包成了一个额外包 是**可选的**

## **②全局注册**
或者换种`vue`的说法，将组件注册到`vue`应用中
```js
import App from "App.vue";
import {createApp} from "vue";
import ElementPlus from "element-plus";
import 'element-plus/dist/index.css'

const app=createApp(App);
app.use(ElementPlus);
app.mount('#app');
```

## **③使用组件**
在任意`<template></template>`中使用`element-plus`库给出的组件【积木库】
```js
<template>
  <el-button type="primary">点我呀！</el-button>
</template>

&

<template>
  <el-button v-bind:icon="edit">编辑</el-button>
</template>

<script>
import { Edit } from '@element-plus/icons-vue'
</script>
```

`element-plus` = 乐高积木包（有各种形状的积木）
`@element-plus/icons-vue` = 乐高小人包（给积木加的小人）
