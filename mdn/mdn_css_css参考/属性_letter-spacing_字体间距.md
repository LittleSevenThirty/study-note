# 📝 CSS `letter-spacing` 属性详解（新手友好版）

## 一、什么是 `letter-spacing`？

`letter-spacing` 是 CSS 中用于**控制文字字符之间间距**的一个属性。

- 默认情况下，每个字体都有自己的“自然字间距”（即字母之间的默认距离）。
- 使用 `letter-spacing`，你可以**手动增加或减少**这个间距，从而让文字看起来更松散或更紧凑。

> ✅ **简单理解**：它就像在每个字母之间“加胶水”或“塞空气”——正值 = 拉开字母，负值 = 挤紧字母。

---

## 二、基本语法

```css
letter-spacing: normal; /* 默认值 */
letter-spacing: 2px; /* 固定像素值 */
letter-spacing: 0.2em; /* 相对当前字体大小 */
letter-spacing: -1px; /* 负值：缩小间距 */
```

### 可用的取值类型：

| 值                              | 说明                                 |
| ------------------------------- | ------------------------------------ |
| `normal`                        | 使用字体默认的字间距（推荐用于正文） |
| `<length>`（如 `2px`, `0.3em`） | 自定义间距，**支持负值**             |
| `inherit` / `initial` / `unset` | 全局关键字（一般新手可暂不深究）     |

> ⚠️ 注意：**不支持百分比 `%`**（虽然规范草案中提到未来可能支持，但目前主流浏览器仅接受 `<length>` 或 `normal`）。

---

## 三、常用单位说明（给新手）

- **`px`（像素）**：固定值，比如 `letter-spacing: 2px` 表示每个字母之间加 2 像素空隙。
- **`em`（相对单位）**：相对于当前元素的 `font-size`。例如：
  - 如果字体是 `16px`，那么 `0.1em = 1.6px`
  - 优点：响应式更好，随字体大小自动缩放。

✅ **建议**：优先使用 `em`，尤其在标题或需要适配不同字号的场景。

---

## 四、实际效果演示（代码 + 说明）

### HTML 示例：

```html
<p class="normal">正常间距</p>
<p class="wide">宽松间距</p>
<p class="tight">紧凑间距</p>
```

### CSS 样式：

```css
.normal {
  letter-spacing: normal;
}
.wide {
  letter-spacing: 0.2em;
} /* 字母拉开 */
.tight {
  letter-spacing: -0.05em;
} /* 字母挤紧 */
```

### 效果对比：

- **正常**：As much mud in the streets...
- **宽松**：A s m u c h m u d ...
- **紧凑**：Asmuchmudinthestreets...

> 🔍 小技巧：适当增加标题的 `letter-spacing`（如 `0.1em`）能让排版更优雅、易读。

---

## 五、重要注意事项（避坑指南）

### 1. **不要过度使用**

- 过大的正值（如 `2em`）会让单词变成“散落的字母”，失去可读性。
- 过大的负值（如 `-0.5em`）会导致字母重叠，难以辨认。

✅ **最佳实践**：微调即可，通常范围在 `-0.05em` 到 `0.2em` 之间。

### 2. **不同字体效果不同**

- 宽字体（如 Arial）和窄字体（如 Impact）对相同 `letter-spacing` 的视觉感受差异很大。
- **没有“万能值”**，需结合具体字体测试调整。

### 3. **与 `word-spacing` 的区别**

- `letter-spacing`：控制**字母之间**的间距。
- `word-spacing`：控制**单词之间**的间距（由空格分隔）。
- 两者可同时使用，互不影响。

---

## 六、无障碍（Accessibility）考量

> 💡 这点很多新手会忽略，但非常重要！

- WCAG（网页无障碍标准）建议：**不要因样式导致文字无法阅读**。
- 极端的 `letter-spacing` 会：
  - 破坏单词完整性（影响阅读障碍用户）
  - 降低屏幕阅读器的语义识别准确性
- ✅ **建议**：正文保持 `normal`，仅在装饰性文本（如 Logo、大标题）中谨慎使用。

---

## 七、浏览器兼容性

- ✅ **广泛支持**：所有现代浏览器（Chrome、Firefox、Safari、Edge）均支持。
- 支持时间：自 **2015 年起**已稳定可用。
- 无需加浏览器前缀（如 `-webkit-`）。

---

## 八、常见应用场景

| 场景               | 推荐值              | 说明           |
| ------------------ | ------------------- | -------------- |
| 大标题（H1/H2）    | `0.05em ~ 0.15em`   | 提升视觉呼吸感 |
| 英文品牌 Logo      | `0.1em ~ 0.3em`     | 增强设计感     |
| 紧凑排版（如标签） | `-0.02em ~ -0.05em` | 节省空间       |
| 正文段落           | `normal`            | 保证可读性     |

---

## 九、小结：关键要点速记

- `letter-spacing` 控制**字母间距**，不是单词间距。
- 值为 `normal`（默认）或 `<length>`（如 `px`、`em`）。
- **支持负值**，但要避免过度挤压。
- **优先用 `em`**，适配性更好。
- **正文慎用**，标题可适度美化。
- **考虑无障碍**，确保文字仍可读。
