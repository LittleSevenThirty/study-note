# **filter**
`filter` 属性就像是网页元素的“美颜相机”或“滤镜库”。它不仅能处理图片，还能作用于背景、边框，甚至是文字和视频。与 `transform` 或 `opacity` 不同，`filter` 专门处理**视觉效果**（如模糊、变色）。

以下是严格按照 MDN 文档结构进行的深度解析：

---

### **CSS 属性：filter**

#### **核心概念**

*   **【原文要点】**
    `filter` 属性用于将模糊（Blur）、颜色偏移（Color Shift）等图形效果应用于元素。它通常被用来调整图像、背景和边框的渲染效果。

*   **【深度拆解】**
    1.  **不仅仅是图片**：很多初学者以为 `filter` 只能用在 `<img>` 标签上，这是错误的。它可以应用在**任何 HTML 元素**上，包括 Div、文字（Text）、甚至是视频。
    2.  **图形处理器（GPU）加速**：大多数 `filter` 效果（如模糊、亮度调整）是由电脑的显卡（GPU）直接处理的。这意味着，相比于用 CSS 背景图片来模拟效果，使用 `filter` 的性能通常更好，动画更流畅。
    3.  **组合拳**：`filter` 的强大之处在于你可以把多个效果叠加在一起，比如既模糊又变亮，或者既灰度化又加阴影。

#### **属性参数表**

*   **【深度拆解】**
    *   **初始值 (`none`)**：默认情况下，元素没有任何特殊滤镜效果。
    *   **适用元素 (All elements)**：所有元素都适用。但在 SVG 中，它不适用于 `<defs>` 元素（定义资源的容器）。
    *   **继承性 (No)**：滤镜效果**不会**被子元素继承。例如，如果你给一个 Div 加了模糊效果，Div 里面的文字不会自动变模糊（除非你单独给文字设置）。
    *   **动画类型**：`filter` 是支持 CSS 动画（Transition/Animation）的。例如，你可以让图片从清晰慢慢变模糊。

#### **形式语法 (Formal Syntax)**

*   **【原文要点】**
    ```css
    filter = none | <filter-value-list>
    <filter-value-list> = [ <filter-function> | <url> ]+
    ```
    *   **含义**：`filter` 的值要么是 `none`，要么是一个或多个“滤镜函数”或“SVG 滤镜引用”的列表。

*   **【深度拆解】**
    *   **`<url>` 的含义**：除了使用内置的函数（如 `blur`），你还可以引用外部的 SVG `<filter>` 元素。这意味着 `filter` 的能力可以无限扩展，利用 SVG 强大的滤镜库（如波浪、扭曲效果）。
    *   **`+` 符号**：表示可以写多个函数。例如 `blur(2px) brightness(1.5)`。

---

### **属性值详解：滤镜函数库**

`filter` 的核心就是这一系列的函数。你可以把它们想象成 Photoshop 里的调整图层。

#### **1. 模糊类：blur()**
*   **【原文要点】**
    将高斯模糊应用于输入图像。
*   **【深度拆解】**
    *   **参数**：接受长度值（如 `px`, `em`），**不能**接受百分比。
    *   **原理**：数值越大，模糊半径越大，图像越看不清。常用于“毛玻璃”（Backdrop Filter）效果或模态框的背景虚化。

#### **2. 调色类：brightness() 与 contrast()**
*   **【原文要点】**
    *   **brightness()**：调整亮度。`0%` 全黑，`100%` 无变化，`>100%` 更亮。
    *   **contrast()**：调整对比度。`0%` 变灰色（无对比），`100%` 无变化，`>100%` 对比更强。
*   **【深度拆解】**
    *   **数值逻辑**：它们都接受百分比或小数。
    *   **特殊效果**：`brightness(0)` 可以用来制作“纯黑遮罩”；`contrast(0)` 可以用来制作“纯色剪影”。

#### **3. 阴影类：drop-shadow()**
*   **【原文要点】**
    沿图像轮廓生成阴影。语法类似 `box-shadow`，但**没有** `inset` 关键字，也**没有** `spread` 参数。阴影也会受到后续滤镜的影响。
*   **【深度拆解】**
    *   **与 Box-Shadow 的区别**：
        *   `box-shadow` 是给元素的“矩形盒子”加阴影，不管图片内部是透明的还是有镂空的。
        *   `drop-shadow` 是给元素的“非透明像素”加阴影。如果图片是圆形或有透明背景，`drop-shadow` 会完美贴合图形边缘。
    *   **语法**：`drop-shadow(h-offset v-offset blur color)`。

#### **4. 色彩变换类：grayscale(), sepia(), saturate(), hue-rotate(), invert()**
*   **【原文要点】**
    *   **grayscale()**：灰度（黑白）。`100%` 完全黑白。
    *   **sepia()**：深褐色（复古照片）。`100%` 完全复古。
    *   **saturate()**：饱和度。`0%` 完全不饱和（灰），`>100%` 色彩更鲜艳。
    *   **hue-rotate()**：色相旋转。接受角度值（`deg`）。`0deg` 无变化，`360deg` 回到原点。
    *   **invert()**：反转颜色。`100%` 颜色完全反转（底片效果）。
*   **【深度拆解】**
    *   **百分比与小数**：这些函数通常接受百分比，但根据 CSS Values Module Level 4，它们也接受小数（例如 `grayscale(0.5)` 等同于 `grayscale(50%)`）。
    *   **创意组合**：`hue-rotate(90deg) saturate(2)` 可以把一张普通的照片变成风格强烈的艺术作品。

#### **5. 透明度：opacity()**
*   **【原文要点】**
    应用透明度。`0%` 完全透明，`100%` 无变化。
*   **【深度拆解】**
    *   **与 `opacity` 属性的区别**：
        *   `opacity` 属性会让元素及其**所有子元素**一起变透明（包括点击事件的穿透感）。
        *   `filter: opacity()` 只改变**当前元素的视觉渲染**。如果这个元素里面有子元素，子元素不会变透明（除非子元素自己也设置了滤镜）。这是一个非常微妙但重要的区别。

### **示例 (Examples)**

#### **应用 filter 函数**

*   **【原文要点】**
    将 `filter` 属性应用于图片，为其本身以及边框添加灰度和模糊效果。

*   **【实例教学】**
    假设我们要做一个“复古模糊”的图片效果。
    ```css
    img {
      filter: grayscale(50%) blur(2px);
    }
    ```
    *   **代码逐行视觉解释**：
        1.  `grayscale(50%)`：首先，图片变成半黑白（还保留一半的颜色）。
        2.  `blur(2px)`：然后，在这个半黑白的图片基础上进行轻微的模糊。
    *   **预期效果**：一张既不是完全黑白，又有点模糊的怀旧风格图片。

#### **重复滤镜函数与顺序**

*   **【原文要点】**
    滤镜函数按声明顺序依次应用。可以重复相同的滤镜函数。示例中提到阴影颜色不同是因为 `hue-rotate()` 改变了第一个阴影的色调，而第二个没有被改变。

*   **【实例教学】**
    这是一个展示**顺序重要性**的经典案例。
    ```css
    /* 示例 1: 先变色，后加阴影 */
    .box1 {
      filter: hue-rotate(90deg) drop-shadow(10px 10px 5px red);
    }

    /* 示例 2: 先加阴影，后变色 */
    .box2 {
      filter: drop-shadow(10px 10px 5px red) hue-rotate(90deg);
    }
    ```
    *   **视觉逻辑拆解**：
        *   **.box1**：浏览器先执行 `hue-rotate(90deg)`，把元素本身的颜色转了 90 度（比如红色变绿色）。然后执行 `drop-shadow`，此时阴影的颜色是基于当前元素的“新颜色”（绿色）生成的。所以你会看到一个**绿色**的阴影。
        *   **.box2**：浏览器先执行 `drop-shadow`，此时元素还是默认的红色，所以生成了一个**红色**的阴影。然后执行 `hue-rotate(90deg)`，这个旋转作用于整个图层（包括原来的红色元素和红色阴影），把它们都转成了绿色。所以你会看到一个绿色的元素和一个绿色的阴影。
    *   **结论**：**顺序决定结果**。`filter` 是流水线作业，后一道工序会影响前一道工序的产出。

### **规格 (Specification)**

*   **【原文要点】**
    *   **Filter Effects Module Level 1**：定义了 `filter` 属性。

*   **【深度拆解】**
    这是 `filter` 的核心标准。虽然现在有更新的 Level 2 和 Level 3 草案，但 Level 1 是目前浏览器支持最广泛的基础。

---

### **浏览器兼容性**

*   **【原文要点】**
    *   **Baseline**：广泛可用。
    *   **状态**：这是一个已经确立的功能，在 2016年9月之后的所有主流浏览器和设备上都可用。
    *   **注意**：部分功能可能支持程度不同。

*   **【深度拆解】**
    *   **历史包袱**：在早期的 WebKit 浏览器（如旧版 Chrome/Safari）中，需要写 `-webkit-filter` 前缀。虽然现在现代浏览器不再需要，但在维护非常老的项目时可能会见到。
    *   **性能警告**：虽然兼容性好，但复杂的滤镜（特别是 `blur`）在低端移动设备上可能会导致页面卡顿。建议在移动设备上谨慎使用高强度的模糊效果。

### **总结与易错提醒**

*   **【易错提醒/注意】**
    1.  **Drop-shadow vs Box-shadow**：
        *   如果你需要阴影贴合不规则图形（如圆形头像、透明 PNG 图标），**必须**使用 `drop-shadow()`。
        *   如果你需要内阴影（inset）或者扩展阴影（spread），**必须**使用 `box-shadow`，因为 `drop-shadow` 不支持这些参数。
    2.  **Blur 的参数单位**：
        *   `blur()` 只接受 `<length>`（如 `px`, `em`），**不能**接受百分比。写 `blur(10%)` 是无效的。
    3.  **Opacity 的陷阱**：
        *   如果你希望一个半透明的弹窗（Modal）后面的背景变暗但内容清晰，不要用 `opacity`（因为内容也会变淡）。应该用 `background-color: rgba(0,0,0,0.5)`。
        *   如果你希望一张图片变透明但上面的文字不透明，使用 `filter: opacity()` 可能会有兼容性风险，更稳妥的做法是把图片作为背景图，或者使用 `::before` 伪元素来应用滤镜。
    4.  **函数顺序**：
        *   记住 `filter` 是从左到右执行的。`blur(5px) brightness(1.5)` 和 `brightness(1.5) blur(5px)` 在视觉上可能差别不大，但在涉及 `hue-rotate` 和 `drop-shadow` 组合时，顺序会导致天壤之别。
