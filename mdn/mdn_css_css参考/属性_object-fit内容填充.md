#### ️ CSS `object-fit` 属性详解

**一句话概括**：
`object-fit` 属性决定了**替换元素**（如 `<img>` 图片、`<video>` 视频）的内容，应该如何去适应它的容器（父元素）的宽度和高度。

你可以把它想象成 **“给照片选相框”** 的规则：

1. **照片** = 图片/视频本身（有它自己的原始尺寸）。
2. **相框** = HTML容器（你设定的宽高，比如 200x200px）。
3. **规则** = `object-fit`（你是要把照片拉变形塞进去？还是裁剪一下塞进去？）。

---

#### 1. 适用对象：谁可以使用？

并不是所有的 HTML 标签都能用这个属性。它只适用于**替换元素**。

- **常见标签**：`<img>`、`<video>`、`<iframe>`、`<canvas>`。
- **前提条件**：为了让 `object-fit` 生效，该元素通常需要有明确的宽高设置（例如 `width: 100%; height: 100%;`），否则它会默认按原图大小显示，看不出“适应”的效果。

---

#### 2. 核心取值：5种适应模式

这是本节课的重点。`object-fit` 有 5 个具体的属性值，每种效果截然不同。

为了方便记忆，我们假设容器是一个 **200x200px 的正方形盒子**，里面要放一张 **风景照（宽高比不是1:1）**。

| 属性值 | 中文含义 | 效果描述 | 类比：放照片进相框 |
| ------ |------ |------ |------ |
| `fill` | 填充 | **默认行为**。图片会被拉伸或压缩，强行填满整个容器。**图片会变形**。 | 不管照片好不好看，硬生生把它撑满相框，照片可能变胖或变瘦。 |
| `contain` | 包含 | 图片保持**原始比例**缩放，直到**整张图**都能放进相框里。**容器可能会有留白**（黑边/白边）。 | 为了不破坏照片，把照片完整地放进去，哪怕相框四周有空隙也没关系。 |
| `cover` | 覆盖 | 图片保持**原始比例**缩放，直到**完全填满**相框。**图片可能会被裁剪**（切掉头或脚）。 | 宁愿裁掉照片多余的部分，也要把相框填满，不留任何空隙。 |
| `none` | 无 | 图片保持**原始尺寸**，不缩放。如果图太大，就溢出；如果图太小，就只占那么一小块。 | 原样贴上去，爱咋咋地。 |
| `scale-down` | 缩小 | **比较智能**。效果等同于 `none` 和 `contain` 中**尺寸较小**的那个。 | 如果照片本来就比相框小，就原样显示（不放大）；如果照片比相框大，就缩小以适应。 |

---

#### 3. 常见场景与代码示例

**基础代码结构**：
首先，你需要给图片一个“容器”并设定尺寸。

```
img {
  width: 200px;  /* 容器宽度 */
  height: 200px; /* 容器高度 */
  object-fit: cover; /* 在这里切换上面的5种值 */
}
```

**场景实战**：

1. **头像/卡片展示 (**`cover`**)**
    - **需求**：用户上传的头像千奇百怪，但你的网页设计要求所有头像必须是正方形且不能变形。
    - **解法**：使用 `object-fit: cover;`。这样头像会自动裁剪成正方形，既填满了格子，又保持了清晰度。
2. **Logo墙/图标 (**`contain`**)**
    - **需求**：展示合作伙伴的 Logo，Logo 有长有方，不能变形，且必须完整显示。
    - **解法**：使用 `object-fit: contain;`。这样长条形的 Logo 会自动缩小显示在框内，四周留白也没关系，重要的是 Logo 完整且不变形。
3. **背景图替代方案**
    - **需求**：你想给一个 div 加背景图，但背景图不能被 SEO 抓取，或者你需要更灵活的控制。
    - **解法**：用 `<img>` 标签配合 `object-fit: cover;`，效果和 `background-size: cover;` 几乎一样，但它是真正的 HTML 内容。

#### 4. 进阶技巧：配合 `object-position`

有时候，使用 `cover` 模式裁剪图片时，系统默认裁剪的位置可能不是你想要的（比如把人物的头裁掉了）。

这时候就需要 `object-position` 属性，它用来控制图片在容器中的**对齐位置**（类似 `background-position`）。

- **语法**：`object-position: x-axis y-axis;`
- **常用值**：`top`, `bottom`, `left`, `right`, `center`，或者百分比/像素值。

**示例**：
你想让图片在裁剪时，**顶部对齐**（保留头顶，裁掉脚）：

```
img {
  width: 200px;
  height: 200px;
  object-fit: cover;
  object-position: top; /* 关键代码：强制顶部对齐 */
}
```

---

#### 5. 新手避坑指南（注意事项）

1. **必须设置宽高**：如果你只写了 `object-fit: cover;`，但没给图片设置固定的 `width` 和 `height`，这个属性通常不会生效，图片还是按原大小显示。
2. **浏览器兼容性**：现代浏览器（Chrome, Firefox, Edge 等）都支持得很好，但如果你需要兼容非常老的 IE 版本（IE10及以下），可能需要使用背景图或者其他 JS 方案作为替代。
3. **不要和 **`background-size`** 混淆**：
    - `background-size`：用在 `div` 等容器的背景上。
    - `object-fit`：用在 `<img>`、`<video>` 这种具体的标签上。
