# Java匿名内部类使用

## 一、什么是匿名内部类

**定义：**没有显示类名的内部类，直接在`new`关键字后通过实现接口或继承父类的方式定义

**特点：**

* 一次性使用（无法复用）
* 直接重写父类/接口的方法
* 可以访问外部类的成员（包括私有成员）



## 二、基本语法

```java
// 继承父类
父类名 对象 = new 父类名(){
    // 重写父类方法
    @Override
    void 方法名(){...}
};

// 实现接口
接口名 对象 = new 接口名(){
    @Override
    void 方法名(){...}
}
```



## 三、注意点

**1.访问外部变量：**

* 只能访问`final`或**等效 final**的局部变量

```java
void outerMethod(){
    final int x = 10;	// final变量
    int y = 20;	// 等效 final（未被修改）
    
    Runnable r = new Runnable(){
        @Override
        public void run(){
            System.out.println(x+y);	//合法
            // y = 30;	// 错误！ y必须等效final
        }
    };
}
```

**2.可以重写多个方法**

**3.隐含持有外部类的引用**



## 四、典型使用场景

‌**事件监听**‌（GUI编程）

**快速实现接口/抽象类**‌：

```java
Thread thread = new Thread(new Runnable() {
    @Override
    public void run() {
        System.out.println("Thread running");
    }
});
thread.start();
```

**简化工厂模式**‌：

```java
interface Logger { void log(String msg); }

class LoggerFactory {
    static Logger createConsoleLogger() {
        return new Logger() {
            @Override
            public void log(String msg) {
                System.out.println("[CONSOLE] " + msg);
            }
        };
    }
}
```
