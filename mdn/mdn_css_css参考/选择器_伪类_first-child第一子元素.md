# CSS `:first-child` 伪类选择器新手笔记

**核心作用一句话**：`:first-child` 用来选中**父元素**下的**第一个子元素**，并对它应用特殊的样式。

---

## 一、基础概念：它是如何工作的？

在开始写代码前，我们需要理解它的两个核心逻辑：

- **位置优先**：它不看元素的类型（是 div 还是 p），它只看**位置**。它选中的是父容器里的“老大”（第一个出生的孩子）。
- **通用性**：它不仅仅能选中 `<p>` 或 `<div>`，它可以附加在**任何**选择器后面，用来匹配“既是某类型，又是第一个子元素”的标签。

---

## 二、语法结构

`selector` 代表你想要选中的元素类型（如 p, div, li）。

```css
/* 语法格式 */
selector:first-child {
  /* 样式规则 */
}

/* 或者只选中第一个子元素（不管它是什么标签） */
:first-child {
  /* 样式规则 */
}
```

---

## 三、核心用法详解

**1. 基本用法：`p:first-child`**

这行代码的意思是：**选中那些“既是 `<p>` 标签”，又是“父元素第一个子元素”的段落。**

- **情况 A（生效）**：
  HTML 结构是：`<p>我是第一个孩子</p>`。
  CSS `p:first-child` 会选中我，因为我既是 P，又是第一个。
- **情况 B（失效）**：
  HTML 结构是：`<span>我是第一个</span><p>我是第二个</p>`。
  CSS `p:first-child` **不会**选中后面的 P，因为在父眼里，第一个孩子是 `<span>`，P 是老二。

**2. 通用用法：`*:first-child` 或 `:first-child`**

如果你只想选中父元素下的第一个子元素，**不管它是什么标签**，可以使用通配符 `*` 或直接写 `:first-child`。

```css
/* 选中父元素下的第一个子元素（无论它是div、p还是img），将其背景变黄 */
:first-child {
  background-color: yellow;
}
```

## 四、实战场景与代码示例

**1. 场景：文章排版（去除首段上边距）**

通常段落 `<p>` 都会有默认的上下边距。在文章开头，我们不希望第一个段落上面有一大块空白，显得突兀。

```css
/* 选中文章容器中第一个子元素，且它是段落时 */
.article p:first-child {
  margin-top: 0; /* 去掉上边距 */
}
```

**2. 场景：导航菜单（去除首项左侧边框）**

在制作横向导航栏时，通常会给每个菜单项加一个左侧边框作为分割线，但第一个菜单前面不需要分割线。

```css
.nav-item {
  border-left: 1px solid #ccc; /* 每个项都有左边框 */
}

.nav-item:first-child {
  border-left: none; /* 第一个子元素去掉左边框 */
}
```

**3. 场景：列表首项特殊样式**

```css
/* 让列表的第一项文字加粗，颜色变红 */
ul li:first-child {
  font-weight: bold;
  color: red;
}
```

## 五、常见误区与避坑指南

这是新手最容易混淆的地方，请务必仔细阅读。

**误区 1：认为 `p:first-child` 是选中“第一个 `<p>`”**

- **错误理解**：只要页面里有多个 `<p>`，就选中排在最前面的那个。
- **正确理解**：必须是父元素的**第一个孩子**，且刚好是 `<p>`。
- **解决方案**：如果你想要选中“父元素里出现的第一个 `<p>`，不管它排第几”，应该使用 `:first-of-type`。

**误区 2：被看不见的空格或换行符干扰**

在 HTML 中，元素之间的换行符和空格，在浏览器解析时可能会被视为“文本节点”。
- 如果你的代码写成这样：
  ```html
  <div>
    <!-- 注意这里有个换行/空格 -->
    <p>我是段落</p>
  </div>
  ```
  严格来说，`<div>` 的第一个子节点可能是一个“空的文本节点”，导致 `p:first-child` 失效。
- **解决方案**：在写 HTML 时，尽量让第一个子元素顶格写（不缩进），或者在 CSS 中使用 `p:first-of-type` 会更稳健。

## 六、对比记忆法

为了帮你更好地记忆，我做了一个简单的对比表：

| 选择器 | 你的“人话”理解 | 适用场景 |
| :--- | :--- | :--- |
| `p:first-child` | “我是我爹的第一个孩子，而且我刚好是儿子（p）。” | 确定第一个子元素就是目标元素时使用。 |
| `p:first-of-type` | “我是我爹所有的儿子（p）里面，年龄最大的那个。” | 父元素里混杂了其他标签（如 img, span），只想找第一个 p 时使用。 |
| `:first-child` | “我是我爹的第一个孩子（不管我是儿子还是闺女）。” | 通用的首项选择，如移除容器第一个元素的 margin。 |

---

## 七、总结

- **`:first-child` 是基于位置的选择器**。
- 它的兼容性非常好，现代浏览器和老版本 IE 都支持（IE8 需要声明文档类型）。
- 当你发现 `:first-child` 选不中元素时，大概率是因为**目标元素前面还有别的兄弟元素**（哪怕是看不见的空格），这时候请尝试使用 `:first-of-type`。
