# CSS `color` 属性新手系统笔记

**核心作用一句话**：`color` 属性用来设置**文本**的**前景色**（也就是我们肉眼看到的字体颜色）。

---

## 一、基础概念：它管什么？

在开始写代码前，我们需要明确它的作用范围：

- **主要职责**：设置 HTML 元素内**文字**的颜色。
- **隐藏职责**：除了文字，它还会影响**文本装饰**的颜色。
    - 比如你给文字加了下划线（`text-decoration: underline`），那条线的颜色会自动跟随文字颜色。
- **“继承”特性**：`color` 是一个**可继承**属性。
    - 如果你给 `<body>` 设置了 `color: red;`，那么页面里所有的文字默认都会变成红色，除非某个特定的段落自己设置了别的颜色。

---

## 二、语法结构

`color` 的语法非常简单，就是指定一个颜色值。

**CSS 语法格式**

```
选择器 {
  color: <color-value>; /* <color-value> 就是你想要的颜色 */
}
```

---

## 三、颜色的 5 种表达方式（核心）

CSS 提供了多种“语言”来描述颜色，新手掌握前 3 种即可，后 2 种了解即可。

**1. 颜色关键字 (Keywords)**

- **定义**：直接用英文单词表示颜色。
- **常用例子**：
    - 基础色：`red`（红）、`green`（绿）、`blue`（蓝）。
    - 常用色：`black`（黑）、`white`（白）、`gray`（灰）、`orange`（橙）。
- **特点**：简单好记，但颜色种类有限（虽然 CSS 规范定义了 140+ 个颜色名，但常用的就那几个）。

**2. 十六进制值 (Hexadecimal)**

- **定义**：这是设计师和前端最常用的格式，以 `#` 开头。
- **格式**：`#RRGGBB`
    - `RR`：红色的浓度（00-FF）。
    - `GG`：绿色的浓度（00-FF）。
    - `BB`：蓝色的浓度（00-FF）。
- **例子**：
    - 纯红：`#FF0000`
    - 纯黑：`#000000`
    - 纯白：`#FFFFFF`
- **简写形式**：如果每种颜色的两位数字都一样，可以简写为 3 位。
    - 例如：`#000` 等同于 `#000000`（黑色）；`#f00` 等同于 `#ff0000`（红色）。

**3. RGB 值 (Red, Green, Blue)**

- **定义**：通过红、绿、蓝三原色的数值来混合颜色。
- **格式**：`rgb(红, 绿, 蓝)`
- **数值范围**：0 - 255。
    - `0` 代表不发光（黑）。
    - `255` 代表最亮。
- **例子**：
    - 白色：`rgb(255, 255, 255)`（三色全开）。
    - 黑色：`rgb(0, 0, 0)`（三色全关）。
- **百分比写法**：也可以用百分比，`0%` 是黑，`100%` 是最亮。例如 `rgb(100%, 0%, 0%)` 是纯红。

**4. RGBA 值 (RGB + Alpha)**

- **定义**：在 RGB 的基础上，增加了一个**透明度**通道。
- **格式**：`rgba(红, 绿, 蓝, 透明度)`
- **透明度 (Alpha)**：取值 0 - 1。
    - `0`：完全透明（看不见）。
    - `1`：完全不透明（实心）。
    - `0.5`：半透明。
- **应用场景**：当你想让文字颜色变淡，或者不想完全挡住背景图时非常有用。

**5. HSL 值 (色相, 饱和度, 亮度)**

- **定义**：一种更符合人类直觉的颜色模型。
- **格式**：`hsl(色相, 饱和度, 亮度)`
- **参数解释**：
    - **色相 (Hue)**：0-360 的数字，代表色轮上的角度。
        - `0` 或 `360` 是红色。
        - `120` 是绿色。
        - `240` 是蓝色。
    - **饱和度 (Saturation)**：0%-100%。
        - `100%` 是鲜艳的颜色。
        - `0%` 是灰色。
    - **亮度 (Lightness)**：0%-100%。
        - `0%` 是黑色。
        - `50%` 是正常亮度。
        - `100%` 是白色。
- **优势**：如果你想把一个颜色调亮一点或调暗一点，用 HSL 比用 RGB 更容易计算。

## 四、官方文档中的特殊值（进阶）

除了上面这些具体的颜色，MDN 文档中还提到了几个特殊的“魔法值”，新手了解即可：

- `currentcolor`：
    - **含义**：这是一个非常有用的“代词”。它表示“当前元素的 color 属性值”。
    - **用途**：当你想让边框颜色（`border-color`）或者背景颜色和文字颜色保持一致时，可以用它。这样改文字颜色时，边框颜色也会自动跟着变。
- `transparent`：
    - **含义**：完全透明。虽然看不见，但有时候用来做占位或者过渡效果很有用。
- **全局值**：
    - `inherit`：继承父元素的颜色。
    - `initial`：恢复为浏览器默认颜色（通常是黑色或深灰色）。

## 五、实战代码示例

这里有几个例子，帮你把上面的概念串起来。

**1. 基础用法**

```
/* 使用颜色名 */
h1 {
  color: blue;
}

/* 使用十六进制 (推荐，最常用) */
p {
  color: #333; /* 深灰色 */
}

/* 使用 RGB */
.warning {
  color: rgb(255, 0, 0); /* 红色 */
}

/* 使用 RGBA (带透明度) */
.faded-text {
  color: rgba(0, 0, 0, 0.3); /* 黑色，但只有 30% 的不透明度，看起来很淡 */
}

/* 使用 HSL */
.beautiful-green {
  color: hsl(120, 100%, 25%); /* 深绿色 */
}
```

**2. 利用继承设置全局颜色**

```
/* 通常在 CSS 开头写这一句，统一全文基调 */
body {
  color: #222; /* 设置一个深灰色作为默认文字色 */
}

/* 单独修改特殊的文字 */
.error {
  color: red;
}
```

**3. 使用 currentcolor (高级技巧)**

```
.fancy-link {
  color: red; /* 文字是红色 */
  border-bottom: 2px solid currentColor; /* 下划线也是红色！ */
  /* 这样以后想改成蓝色，只需要改 color: blue; 下划线自动变蓝 */
}
```

## 六、总结与避坑指南

- **首选十六进制**：对于新手，建议先熟练使用**十六进制**（`#RRGGBB` 或 `#RGB`），因为设计稿（如 Figma, Sketch）通常都导出这个格式，且兼容性最好。
- **RGBA 用于透明**：需要半透明效果时，果断使用 RGBA。
- **不要用纯黑**：在白色背景上，`#000000`（纯黑）对眼睛刺激较大。正文通常推荐使用深灰色（如 `#333333`）。
- **注意对比度**：文字颜色和背景颜色要有足够的对比度，否则用户看不清（比如浅黄字配白背景是读不了的）。
