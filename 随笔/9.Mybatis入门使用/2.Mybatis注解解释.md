# Mybatis注解解释

## 注解

### @Mapper

* **作用：**
  标识接口为MyBatis映射器接口，编译后自动生成实现类，简化数据库操作接口的配置

* **功能：**

  * 与XML映射文件或注解式SQL绑定，实现数据库操作
  * 替代手动编写DAO层实现类，提升开发效率

* **示例：**

  ```java
  @Mapper
  public interface UserMapper{
      @Select("select * from user where id = #{id}")
      User selectById(int id);
  }
  ```

  

### @MapperScan

* **作用：**
  批量扫描制定包下的接口并注册为MyBatis映射器，避免逐一声明@Mapper
* **功能：**
  * 支持多包路径、通配符匹配（如`com.example.*.mapper`）
  * 可结合`sqlSessionFactory`或`sqlSessionTemplate`进行扩展配置

* **示例：**

  ```java
  @SpringBootApplication
  @MapperScan({"com.example.mapper", "com.example.sub.mapper"})
  public class Application {
      public static void main(String[] args) {
          SpringApplication.run(Application.class, args);
      }
  }
  
  ```

  

### @Param

- ‌**作用：**‌
  在 **Mapper 接口方法**，如果出现**多个传递参数**需要**通过 `@Param` 注解为每个参数命名，然后在 XML 中通过名称引用参数。**因为java反射后所有参数的名称都会变为arg0,arg1**
- ‌**功能：**‌
  - 指定XML中参数引用名称，避免因参数顺序或命名导致的错误。
  - 支持基本类型、对象类型参数绑定。

* **示例：**
  接口定义

  ```java
  public interface UserMapper {
      User selectUserByNameAndEmail(
          @Param("person") Person person
      );
  }
  ```
  
  UserMapper.XML配置
  ```xml
  <select id="selectUserByNameAndEmail" resultType="User">
      SELECT * FROM user 
      WHERE name = #{person.name} 
      AND email = #{person.email}
  </select>
  ```
