# Docker使用
>**Docker 学习要点**
> 1.核心组件
> - 必须安装 ‌**Docker Engine**‌（Linux 直接安装，Windows/macOS 推荐 Docker Desktop）。
> - 推荐安装 ‌**Docker Compose**‌（多容器编排工具，Docker Desktop 已内置）。
>
> 2. ‌图形化工具
> * **Docker Desktop**‌：官方 GUI，适合新手，集成 Engine 和 Compose。
> * **Portainer**‌：通过容器部署（需挂载 Docker Socket），适合所有系统。
>
> 3.进阶建议
> - 学习 Dockerfile 和 Compose 文件语法。
> - 熟悉镜像仓库（如 Docker Hub）的使用。
> - 优先掌握常用命令和容器生命周期管理。


## 学习资源推荐

- ‌**文档**‌：[Docker 官方文档](https://docs.docker.com/)（最权威）
- ‌**实践**‌：通过项目练手（如部署 WordPress + MySQL）
- ‌**社区**‌：GitHub 开源项目、Stack Overflow 问题排查
