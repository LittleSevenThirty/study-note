# Mybatis使用指南

当前环境：IDEA2024.3 + MySQL8.0

## 1.环境准备

* **创建项目后**：在`pom.xml`文件里添加依赖

  ```xml
  <!-- MyBatis -->
  <dependency>
      <groupId>org.mybatis</groupId>
      <artifactId>mybatis</artifactId>
      <version>3.5.7</version>
  </dependency>
  <!-- 数据库驱动（以MySQL为例） -->
  <!-- 但如果使用的是MySQL8.0.27，官方推荐使用mysql-connector-j包-->
  <dependency>
      <groupId>mysql</groupId>
      <artifactId>mysql-connector-java</artifactId>
      <version>8.0.25</version>
  </dependency>
  ```

## 2. [配置文件](https://mybatis.org/mybatis-3/zh_CN/configuration.html)

* **mybatis-config.xml：**配置数据源和Mapper路径（或使用Spring Boot的`application.yml`)

  ```xml
  <configuration>
      <environments default="development">
          <environment id="development">
              <transactionManager type="JDBC"/>
              <dataSource type="POOLED">
                  <property name="driver" value="com.mysql.cj.jdbc.Driver"/>
                  <property name="url" value="jdbc:mysql://localhost:3306/test?useSSL=false"/>
                  <property name="username" value="root"/>
                  <property name="password" value="123456"/>
              </dataSource>
          </environment>
      </environments>
      <mappers>
          <!-- 指定Mapper.xml路径 -->
          <!-- <mapper resource="对应Mapper.xml文件路径(例子如下)"/> -->
          <mapper resource="resources/mybatis/mapper/UserMapper.xml"/>
      </mappers>
  </configuration>
  ```




## 3. 实体类与Mapper接口

* **实体类：**对应创建数据库表结构，例如：

  ```java
  public class User{
      private Integer id;
      private String name;
      private String email;
  }
  ```

* **Mapper接口：**使用`@Mapper`注解标记的接口类（或使用了Spring Boot启动类添加了@MapperScan注解）

  ```java
  @Mapper
  public interface UserMapper{
      User selectUserById(Integer id);
  }
  ```

  ```java
  //偷懒的话，假如上面的接口类属于cn.example.mapper包，而Application.java主类在cn.example包下
  //可以使用@MapperScan注解来减少自己添加@Mapper注解的麻烦
  @SpringBootApplication
  @Configuration
  @MapperScan("cn.example.mapper")
  public class Application{
      public static void main(String[] args){
          SpringApplication.run(Application.class);
      }
  }
  ```



## 4. Mapper接口对应的Mapper.xml文件

* **UserMapper.xml：**Sql与接口方法绑定

  ```java
  <?xml version="1.0" encoding="UTF-8"?>
  <!DOCTYPE mapper PUBLIC "-//mybatis.org//DTD Mapper 3.0//EN" "http://mybatis.org/dtd/mybatis-3-mapper.dtd">
  <mapper namespace="com.example.mapper.UserMapper">
      <select id="selectUserById" resultType="com.example.entity.User">
          SELECT * FROM user WHERE name = #{name}
      </select>
      <!-- Mybatis支持所有的CRUD -->
  </mapper>
  ```



## 6. 整合Spring Boot简化配置

- **依赖**：添加Spring Boot Starter：

  ```xml
  <dependency>
      <groupId>org.mybatis.spring.boot</groupId>
      <artifactId>mybatis-spring-boot-starter</artifactId>
      <version>2.2.0</version>
  </dependency>
  ```
  

​	**补充：**<font color=red>添加Spring Boot Starter依赖后，SpringBoot会扫描主启动类的软件包及子包，并将所有的类，接口集中让IOC容器进行管理，之后就可以使用依赖注入的方式管理对象</font>

- **application.yml**：

  ```yaml
  spring:
    datasource:
      url: jdbc:mysql://localhost:3306/my_DB_name		<- 数据库url后跟数据库名称
      username: root									<- 用户名
      password: 123456								<- 用户密码
      driver-class-name: com.mysql.cj.jdbc.Driver		<- 数据库驱动名称（这里使用MySQL8）
  mybatis:
    mapper-locations: classpath:mapper/*.xml			<- 定义Mapper.xml文件的位置
    config-locations: classpath:mapper/确切的名称config.xml
  ```

​	**补充：**<font color=red>config-locations和mapper-locations默认根目录在resouces</font>

- **启动类**：添加`@MapperScan`扫描Mapper接口：

  ```java
  @SpringBootApplication
  @MapperScan("com.example.mapper")
  public class Application {
      public static void main(String[] args) {
          SpringApplication.run(Application.class, args);
      }
  }
  ```

## **7. 常见问题排查**

- **错误：Invalid bound statement (not found)**

  - 检查Mapper.xml的`namespace`是否与接口全限定名一致。
  - 确认`mybatis.mapper-locations`路径正确。

- **SQL日志输出**
  在`application.yml`中开启MyBatis日志：

  ```yaml
  logging:
    level:
      com.example.mapper: debug
  ```
