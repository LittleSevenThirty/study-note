# **CSS `text-align` 属性新手系统笔记**

**核心作用一句话**：`text-align` 是用来设置**块级元素**内部的**行内内容**（比如文字、图片、按钮等）**水平对齐方式**的。

---

#### 一、基础概念：它到底控制谁？

在学习具体代码前，先要搞清楚它的“管辖范围”：

- **作用对象**：它设置的是**块级元素**（如 `<div>`、`<p>`、`<h1>`）内部的**行内内容**。
- **类比理解**：想象你有一个大盒子（块级元素），盒子里装了很多小积木（文字、图片）。`text-align` 就是你指挥这些小积木在盒子里怎么站队（靠左站、靠右站、中间站）。
- **重要区别**：
    - `text-align: center;` 是让**文字居中**。
    - `margin: 0 auto;` 是让**盒子（元素本身）居中**。不要混淆。

---

#### 二、语法结构

`text-align` 的写法非常简单，通常直接指定一个关键字值即可。

**CSS 语法格式**

```
/* 基本写法 */
选择器 {
  text-align: 值;
}

/* 全局继承写法 */
选择器 {
  text-align: inherit; /* 从父元素继承对齐方式 */
  text-align: initial; /* 使用默认值 */
  text-align: unset;   /* 重置为未设置状态 */
}
```

---

#### 三、核心取值详解（重点）

`text-align` 有很多值，我们按**常用程度**和**新旧程度**来分类讲解。

**1. 最常用的四个经典值**

这四个值是所有浏览器都支持的，也是你最常会用到的。

- `left`** (左对齐)**：
    - **效果**：文字紧贴容器的**左边**。
    - **注意**：在中文、英文等从左往右书写的语言中，这是**默认值**。
- `right`** (右对齐)**：
    - **效果**：文字紧贴容器的**右边**。
- `center`** (居中对齐)**：
    - **效果**：文字在容器中**水平居中**。
    - **提示**：这是实现文字居中最常用的方法。
- `justify`** (两端对齐)**：
    - **效果**：文字的左右两边都撑满容器，看起来非常整齐（像报纸排版）。
    - **原理**：浏览器会自动调整字与字、词与词之间的间距来填满一行。
    - **注意**：最后一行通常无效（还是左对齐），且在中文中效果可能不如英文明显。

**2. 更智能的逻辑值 (推荐)**

随着网页需要支持多语言（比如阿拉伯语是从右往左写的），使用 `left`/`right` 可能会出问题。W3C 推荐使用逻辑值。

- `start`** (起始边对齐)**：
    - **效果**：如果语言是从左往右（如中文、英文），它就等于 `left`；如果语言是从右往左（如阿拉伯语），它就等于 `right`。
    - **优势**：自动适应文档的语言方向，更灵活。
- `end`** (结束边对齐)**：
    - **效果**：与 `start` 相反。如果是从左往右的语言，它等于 `right`；反之等于 `left`。

**3. 特殊值**

- `match-parent`：
    - **效果**：类似 `inherit`，但会根据父元素的方向（`direction`）来计算 `start` 和 `end` 的实际位置。
- `justify-all`：
    - **效果**：和 `justify` 类似，但**强制让最后一行也两端对齐**。

#### 四、官方文档中的关键细节（新手必看）

为了让你更深入理解，这里整理了文档中容易被忽略但很重要的点：

**1. 它是“传染性”很强的属性**

- `text-align` 是一个**可继承**的属性。
- **含义**：如果你给 `<body>` 标签设置了 `text-align: right;`，那么页面里所有的段落、标题等文字都会默认跑到右边去，除非你单独给某个段落设置 `text-align: left;` 来覆盖它。
- **应用**：通常我们会直接在 `body` 上设置一个全局的文本对齐方式，然后在局部微调。

**2. 关于 **`justify`** 的排版细节**

- 浏览器为了实现两端对齐，会调整**字母间距**（letter-spacing）和**单词间距**（word-spacing）。
- 如果你已经手动设置了 `letter-spacing` 且值很大，浏览器可能无法再进一步拉伸间距来实现完美的两端对齐，这时候效果可能会打折扣。

**3. 默认值的微妙之处**

- 虽然通常说默认是 `left`，但严格来说，它的默认值取决于文档方向：
    - 如果是 `ltr`（从左往右），默认是 `left`。
    - 如果是 `rtl`（从右往左），默认是 `right`。

#### 五、实战代码示例

这里有几个简单的例子，帮你把上面的概念串起来。

**1. 基础用法**

```
/* 让所有段落文字居中 */
p {
  text-align: center;
}

/* 让类名为 .note 的盒子文字右对齐 */
.note {
  text-align: right;
}
```

**2. 两端对齐效果**

```
.article {
  width: 300px; /* 设定一个宽度，否则撑不满看不出效果 */
  text-align: justify;
}
```

```
<div class="article">
  这是一段很长的文字内容... (浏览器会自动把每一行的字间距拉开，让左右边缘整齐)
</div>
```

**3. 全局设置与局部覆盖**

```
/* 全局设置：整个页面文字靠左 */
body {
  text-align: start; /* 推荐使用 start 代替 left */
}

/* 局部覆盖：只有标题要居中 */
h1, h2 {
  text-align: center;
}
```

---

#### 六、总结与避坑指南

- **只对块级元素有效**：你不能对一个 `<span>`（行内元素）使用 `text-align` 来对齐它自己，它是用来对齐**块级元素内部**的内容的。
- **不只是对齐文字**：除了文字，它也能对齐块级元素内部的**行内块元素**（`display: inline-block`）或**图片**。
- **新手建议**：在写中文网页时，先掌握 `left`、`center`、`right`、`justify` 这四个就够了。如果涉及国际化项目，再尝试使用 `start` 和 `end`。
