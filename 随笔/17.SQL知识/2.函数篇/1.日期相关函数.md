# 日期相关函数

## 自己理解

### datediff函数

**解释：**计算两个日期之间的差值

**语法：**

```sql
datediff(datepart,startDate,endDate);
```

**参数：**

* datepart：计算差值时的时间单位，可取值有=》`yy`(年)，`qq`(季度)，`mm`(月)，`dd`(天)，`hh`(小时)，`ss`(秒)
* startDate：开始时间
* endDate：截止时间

**示例：**

```sql
-- 计算从2024年1月1号到2025年2月1号间有多少个月
SELECT DATEDIFF(MM,'2024-01-01','2025-02-01');
```





### getdate函数

**解释：**返回当前系统的日和时间，格式就是`yyyy-mm-dd hh:mm:ss`，没有任何参数

**语法：**

```sql
getdate();
```
