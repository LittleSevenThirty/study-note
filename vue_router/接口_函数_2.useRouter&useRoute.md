## 🧭 一、基本概念

### 1. `useRouter()`
- 返回的是 **路由器实例（router instance）**。
- 相当于 Vue 2 中的 `this.$router`。
- 用于 **导航操作**，比如跳转页面、前进后退等。

常用方法：
```ts
router.push('/home')       // 跳转
router.replace('/login')   // 替换当前记录（不会留下历史）
router.go(-1)              // 后退一页
router.back()              // 等价于 go(-1)
router.forward()           // 等价于 go(1)
```

### 2. `useRoute()`
- 返回的是 **当前激活的路由对象（route object）**。
- 相当于 Vue 2 中的 `this.$route`。
- 用于 **读取当前路由信息**，如路径、参数、查询字符串等。

常用属性：
```ts
route.path        // 当前路径，如 '/user/123'
route.params      // 动态参数，如 { id: '123' }
route.query       // 查询参数，如 { page: '2', q: 'vue' }
route.name        // 路由名称（如果定义了 name）
route.fullPath    // 完整路径（含 query）
```

> ✅ 注意：`useRoute()` 返回的是一个 **响应式对象（reactive）**，所以你可以在模板或计算属性中直接使用它，当 URL 变化时会自动更新！

## 🛠️ 二、如何使用（代码示例）

假设你有一个这样的路由配置：

```js
// router/index.js
import { createRouter, createWebHistory } from 'vue-router'

const routes = [
  { path: '/', component: () => import('@/views/Home.vue') },
  { path: '/user/:id', name: 'User', component: () => import('@/views/User.vue') },
]

const router = createRouter({
  history: createWebHistory(),
  routes
})

export default router
```

### 在组件中使用：

```vue
<!-- User.vue -->
<script setup>
import { useRouter, useRoute } from 'vue-router'
import { ref, watch } from 'vue'

const router = useRouter()
const route = useRoute()

// 读取动态参数
console.log('用户ID:', route.params.id) // 如 '123'

// 读取查询参数
console.log('查询参数:', route.query.page) // 如 '2'

// 跳转到首页
function goHome() {
  router.push('/')
}

// 监听路由变化（比如参数变了）
watch(() => route.params.id, (newId) => {
  console.log('用户ID变了:', newId)
  // 可以在这里重新获取用户数据
})
</script>

<template>
  <div>
    <h1>用户页面 - ID: {{ route.params.id }}</h1>
    <p>页码: {{ route.query.page || '未指定' }}</p>
    <button @click="goHome">返回首页</button>
  </div>
</template>
```

## 🔍 三、关键区别总结

| 特性 | `useRouter()` | `useRoute()` |
|------|---------------|--------------|
| 类型 | 路由器实例（可操作） | 当前路由对象（只读） |
| 用途 | 导航（push/replace/go） | 获取路径、参数、查询等 |
| 响应式 | ❌ 方法不是响应式的 | ✅ 整个对象是响应式的 |
| 对应 Vue 2 | `this.$router` | `this.$route` |

## 💡 四、常见使用场景

### 1. 页面跳转 + 携带参数
```js
router.push({ name: 'User', params: { id: '456' } })
// 或
router.push({ path: '/user/456', query: { tab: 'profile' } })
```

### 2. 权限拦截（配合导航守卫）
虽然导航守卫通常写在 router 配置里，但在组件内也可以用 `router.beforeEach`（不推荐），更常见的是在跳转前做判断：
```js
if (!isLoggedIn) {
  router.push('/login')
}
```

### 3. 动态加载数据（监听 route 变化）
当你在 `/user/1` 切换到 `/user/2` 时，组件不会重新创建（因为是同一个组件），所以需要用 `watch(route)` 来响应参数变化。

## ⚠️ 五、注意事项

1. **只能在 `<script setup>` 或 `setup()` 中使用**  
   这两个函数依赖于 `getCurrentInstance()`，必须在组件 setup 阶段调用。

2. **不要解构 `useRoute()` 的返回值（除非用 toRefs）**  
   因为它是响应式的 proxy，直接解构会失去响应性：
   ```js
   // ❌ 错误：失去响应性
   const { params } = useRoute()

   // ✅ 正确：保持响应性
   const route = useRoute()
   // 或
   const { params } = toRefs(useRoute())
   ```

3. **在非组件环境（如工具函数）中无法使用**  
   如果你需要在 store 或 utils 中跳转，可以把 router 实例导出并直接使用：
   ```js
   // router/index.js
   export { router }

   // utils/auth.js
   import { router } from '@/router'
   router.push('/login')
   ```

## 📚 六、扩展知识

- **路由元信息（meta）**：可以通过 `route.meta` 访问，常用于权限控制、页面标题等。
- **编程式导航 vs 声明式导航**：
  - 声明式：`<router-link to="/home">`
  - 编程式：`router.push(...)`
- **路由懒加载**：结合 `import()` 实现按需加载组件，提升性能。
