# Swiper Vue.js 组件（中文整理版）

> 重要提示：Swiper Vue.js 组件未来版本可能会被移除，建议迁移至 Swiper Element。若从 Swiper 9 升级到 Swiper 10，请查阅《Swiper 10 迁移指南》；如需 v9 版本文档，可访问 v9.swiperjs.com。

## 一、安装

Swiper Vue.js 插件仅可通过 NPM 安装，作为主 Swiper 库的一部分：

```bash
npm i swiper
```

## 二、使用

`swiper/vue` 导出两个核心组件：`Swiper`（轮播容器）和 `SwiperSlide`（轮播滑块）。

### 基础使用示例

```vue
<template>
  <swiper
    :slides-per-view="3"  <!-- 每页显示3个滑块 -->
    :space-between="50"   <!-- 滑块间距50px -->
    @swiper="onSwiper"    <!-- 轮播初始化回调 -->
    @slideChange="onSlideChange"  <!-- 滑块切换回调 -->
  >
    <swiper-slide>滑块1</swiper-slide>
    <swiper-slide>滑块2</swiper-slide>
    <swiper-slide>滑块3</swiper-slide>
    ...
  </swiper>
</template>

<script>
// 导入Swiper Vue组件
import { Swiper, SwiperSlide } from 'swiper/vue';
// 导入Swiper基础样式
import 'swiper/css';

export default {
  components: { Swiper, SwiperSlide },
  setup() {
    // 获取轮播实例
    const onSwiper = (swiper) => {
      console.log(swiper);
    };
    // 滑块切换时触发
    const onSlideChange = () => {
      console.log('滑块切换');
    };
    return { onSwiper, onSlideChange };
  },
};
</script>
```

### 引入扩展模块（导航、分页等）

默认情况下，Swiper Vue 使用核心版本（无扩展功能）。若需使用导航、分页等功能，需先导入对应模块：

#### 可用扩展模块列表（从 `swiper/modules` 导入）

| 模块名          | 功能描述                        |
| --------------- | ------------------------------- |
| Virtual         | 虚拟滑块模块（海量滑块优化）    |
| Keyboard        | 键盘控制模块                    |
| Mousewheel      | 鼠标滚轮控制模块                |
| Navigation      | 导航模块（上/下一张按钮）       |
| Pagination      | 分页模块（圆点/数字指示器）     |
| Scrollbar       | 滚动条模块                      |
| Parallax        | 视差效果模块                    |
| FreeMode        | 自由滑动模式模块                |
| Grid            | 网格布局模块                    |
| Manipulation    | 滑块操作模块（仅核心版本可用）  |
| Zoom            | 缩放模块                        |
| Controller      | 控制器模块（多轮播联动）        |
| A11y            | 无障碍访问模块                  |
| History         | 历史导航模块                    |
| HashNavigation  | 哈希导航模块                    |
| Autoplay        | 自动播放模块                    |
| EffectFade      | 淡出效果模块                    |
| EffectCube      | 立方体效果模块                  |
| EffectFlip      | 翻转效果模块                    |
| EffectCoverflow | 封面流效果模块                  |
| EffectCards     | 卡片效果模块                    |
| EffectCreative  | 创意效果模块                    |
| Thumbs          | 缩略图模块（主轮播+缩略图联动） |

#### 带扩展模块的使用示例

```vue
<template>
  <swiper
    :modules="modules"  <!-- 注入所需模块 -->
    :slides-per-view="3"
    :space-between="50"
    navigation  <!-- 启用导航（自动创建按钮） -->
    :pagination="{ clickable: true }"  <!-- 启用分页（可点击） -->
    :scrollbar="{ draggable: true }"  <!-- 启用滚动条（可拖动） -->
    @swiper="onSwiper"
    @slideChange="onSlideChange"
  >
    <swiper-slide>滑块1</swiper-slide>
    <swiper-slide>滑块2</swiper-slide>
    <swiper-slide>滑块3</swiper-slide>
    ...
  </swiper>
</template>

<script>
// 导入核心模块和所需扩展模块
import { Navigation, Pagination, Scrollbar, A11y } from 'swiper/modules';
// 导入Swiper Vue组件
import { Swiper, SwiperSlide } from 'swiper/vue';
// 导入基础样式和模块专属样式
import 'swiper/css';
import 'swiper/css/navigation';  // 导航模块样式
import 'swiper/css/pagination';  // 分页模块样式
import 'swiper/css/scrollbar';   // 滚动条模块样式

export default {
  components: { Swiper, SwiperSlide },
  setup() {
    const onSwiper = (swiper) => {
      console.log(swiper);
    };
    const onSlideChange = () => {
      console.log('滑块切换');
    };
    // 注册所需模块
    return {
      onSwiper,
      onSlideChange,
      modules: [Navigation, Pagination, Scrollbar, A11y]
    };
  },
};
</script>
```

> 注意：若未指定具体元素（如 `navigation.nextEl`、`pagination.el`），Swiper Vue 组件会自动创建导航、分页、滚动条所需的 DOM 元素。

## 四、核心属性与事件

### 1. Swiper 组件属性（Props）

Swiper 组件支持所有 Swiper 原生参数，额外新增以下专属属性：

| 属性名     | 类型   | 默认值 | 描述                   |
| ---------- | ------ | ------ | ---------------------- |
| tag        | string | 'div'  | 轮播容器的 HTML 标签   |
| wrapperTag | string | 'div'  | 滑块包裹层的 HTML 标签 |

### 2. Swiper 组件事件（Events）

支持所有 Swiper 原生事件，额外新增 `swiper` 事件（优先返回轮播实例）：

```vue
<swiper
  @swiper="获取实例"
  @slideChange="滑块切换时触发"
  @reachEnd="滑动到最后一张时触发"
  @touchStart="触摸开始时触发"
  ...
></swiper>
```

### 3. SwiperSlide 组件属性（Props）

| 属性名       | 类型    | 默认值 | 描述                               |
| ------------ | ------- | ------ | ---------------------------------- |
| tag          | string  | 'div'  | 滑块的 HTML 标签                   |
| zoom         | boolean | false  | 启用缩放模式所需的额外包裹层       |
| virtualIndex | number  | -      | 虚拟滑块的实际索引（虚拟滑块必传） |

### 4. SwiperSlide 插槽属性（Slot Props）

可通过插槽属性获取滑块状态：

```vue
<swiper>
  <swiper-slide v-slot="{ isActive, isPrev, isNext, isVisible, isDuplicate }">
    <div>当前滑块{{ isActive ? '是' : '不是' }}激活状态</div>
    <div>当前滑块{{ isPrev ? '是' : '不是' }}上一张滑块</div>
    <div>当前滑块{{ isNext ? '是' : '不是' }}下一张滑块</div>
    <div>当前滑块{{ isVisible ? '可见' : '不可见' }}（需启用 watchSlidesProgress）</div>
    <div>当前滑块{{ isDuplicate ? '是' : '不是' }}复制滑块（需启用 loop 模式）</div>
  </swiper-slide>
</swiper>
```

## 五、实用钩子（Hooks）

### 1. useSwiper（获取轮播实例）

在 Swiper 内部组件中快速获取轮播实例，用于手动控制轮播：

```vue
<!-- 内部组件.vue -->
<template>
  <button @click="swiper.slideNext()">切换到下一张</button>
</template>

<script>
import { useSwiper } from "swiper/vue";

export default {
  setup() {
    const swiper = useSwiper(); // 获取父级 Swiper 实例
    return { swiper };
  },
};
</script>
```

### 2. useSwiperSlide（获取滑块状态）

在 SwiperSlide 内部组件中获取滑块状态（与插槽属性一致）：

```vue
<!-- 内部组件.vue -->
<template>
  <p>当前滑块{{ swiperSlide.isActive ? "激活" : "未激活" }}</p>
</template>

<script>
import { useSwiperSlide } from "swiper/vue";

export default {
  setup() {
    const swiperSlide = useSwiperSlide();
    return { swiperSlide };
  },
};
</script>
```

## 六、插槽（Slots）

Swiper 组件提供 4 个插槽用于内容分发：

```vue
<swiper>
  <swiper-slide>滑块1</swiper-slide>
  <swiper-slide>滑块2</swiper-slide>
  <!-- 轮播容器开头 -->
  <template v-slot:container-start><span>容器开头</span></template>
  <!-- 轮播容器结尾（默认插槽） -->
  <template v-slot:container-end><span>容器结尾</span></template>
  <!-- 滑块包裹层开头 -->
  <template v-slot:wrapper-start><span>包裹层开头</span></template>
  <!-- 滑块包裹层结尾 -->
  <template v-slot:wrapper-end><span>包裹层结尾</span></template>
</swiper>
```

### 渲染结果

```html
<div class="swiper">
  <span>容器开头</span>
  <div class="swiper-wrapper">
    <span>包裹层开头</span>
    <div class="swiper-slide">滑块1</div>
    <div class="swiper-slide">滑块2</div>
    <span>包裹层结尾</span>
  </div>
  <span>容器结尾</span>
</div>
```

## 七、高级功能

### 1. 虚拟滑块（Virtual Slides）

用于渲染海量滑块（如 1000+ 张），优化性能：

```vue
<template>
  <swiper
    :modules="[Virtual]"
    :slides-per-view="3"
    :space-between="50"
    virtual  <!-- 启用虚拟滑块 -->
  >
    <swiper-slide
      v-for="(slideContent, index) in slides"
      :key="index"
      :virtualIndex="index"  <!-- 必传：虚拟滑块索引 -->
    >
      {{ slideContent }}
    </swiper-slide>
  </swiper>
</template>

<script>
import { Virtual } from 'swiper/modules';
import { Swiper, SwiperSlide } from 'swiper/vue';

export default {
  components: { Swiper, SwiperSlide },
  setup() {
    // 生成 1000 个滑块数据
    const slides = Array.from({ length: 1000 }).map(
      (_, index) => `滑块 ${index + 1}`
    );
    return { slides, Virtual };
  },
};
</script>
```

### 2. 控制器（Controller，多轮播联动）

#### 单向控制（A 控制 B）

```vue
<template>
  <!-- 主轮播：控制目标轮播 -->
  <swiper
    :modules="[Controller]"
    :controller="{ control: controlledSwiper }"
    ...
  >
    ...
  </swiper>

  <!-- 目标轮播：暴露实例给主轮播 -->
  <swiper
    :modules="[Controller]"
    @swiper="setControlledSwiper"  <!-- 存储目标轮播实例 -->
    ...
  >
    ...
  </swiper>
</template>

<script>
import { ref } from 'vue';
import { Controller } from 'swiper/modules';
import { Swiper, SwiperSlide } from 'swiper/vue';

export default {
  components: { Swiper, SwiperSlide },
  setup() {
    const controlledSwiper = ref(null);
    const setControlledSwiper = (swiper) => {
      controlledSwiper.value = swiper; // 保存目标轮播实例
    };
    return { Controller, controlledSwiper, setControlledSwiper };
  },
};
</script>
```

#### 双向控制（A 控制 B，B 控制 A）

```vue
<template>
  <swiper
    :modules="[Controller]"
    @swiper="setFirstSwiper"
    :controller="{ control: secondSwiper }"  <!-- 控制第二个轮播 -->
    ...
  >
    ...
  </swiper>

  <swiper
    :modules="[Controller]"
    @swiper="setSecondSwiper"
    :controller="{ control: firstSwiper }"  <!-- 控制第一个轮播 -->
    ...
  >
    ...
  </swiper>
</template>

<script>
import { ref } from 'vue';
import { Controller } from 'swiper/modules';
import { Swiper, SwiperSlide } from 'swiper/vue';

export default {
  components: { Swiper, SwiperSlide },
  setup() {
    const firstSwiper = ref(null);
    const secondSwiper = ref(null);
    const setFirstSwiper = (swiper) => firstSwiper.value = swiper;
    const setSecondSwiper = (swiper) => secondSwiper.value = swiper;
    return {
      Controller, firstSwiper, secondSwiper, setFirstSwiper, setSecondSwiper
    };
  },
};
</script>
```

### 3. 缩略图（Thumbs，主轮播+缩略图联动）

```vue
<template>
  <!-- 主轮播：关联缩略图轮播 -->
  <swiper
    :modules="[Thumbs]"
    :thumbs="{ swiper: thumbsSwiper }"  <!-- 传入缩略图实例 -->
    ...
  >
    ...
  </swiper>

  <!-- 缩略图轮播：暴露实例给主轮播 -->
  <swiper
    :modules="[Thumbs]"
    watch-slides-progress  <!-- 必传：监听滑块进度 -->
    @swiper="setThumbsSwiper"  <!-- 存储缩略图实例 -->
    :slides-per-view="4"  <!-- 缩略图每页显示4个 -->
    ...
  >
    ...
  </swiper>
</template>

<script>
import { ref } from 'vue';
import { Thumbs } from 'swiper/modules';
import { Swiper, SwiperSlide } from 'swiper/vue';

export default {
  components: { Swiper, SwiperSlide },
  setup() {
    const thumbsSwiper = ref(null);
    const setThumbsSwiper = (swiper) => {
      thumbsSwiper.value = swiper; // 保存缩略图轮播实例
    };
    return { Thumbs, thumbsSwiper, setThumbsSwiper };
  },
};
</script>
```

### 4. 切换效果（Effects）

支持 6 种切换效果，使用前需导入对应模块并引入样式：

| 效果名称  | 模块名          | 效果描述               |
| --------- | --------------- | ---------------------- |
| Fade      | EffectFade      | 淡出切换（淡入淡出）   |
| Cube      | EffectCube      | 立方体切换             |
| Coverflow | EffectCoverflow | 封面流切换（类似相册） |
| Flip      | EffectFlip      | 翻转切换               |
| Cards     | EffectCards     | 卡片堆叠切换           |
| Creative  | EffectCreative  | 自定义创意切换         |

#### 淡出效果（Fade）完整示例

```vue
<template>
  <swiper
    :modules="[EffectFade]"
    effect="fade"  <!-- 指定效果类型 -->
    :fade-effect="{ crossFade: true }"  <!-- 效果参数（可选） -->
  >
    <swiper-slide>滑块1</swiper-slide>
    <swiper-slide>滑块2</swiper-slide>
    <swiper-slide>滑块3</swiper-slide>
  </swiper>
</template>

<script>
import { EffectFade } from 'swiper/modules';
import { Swiper, SwiperSlide } from 'swiper/vue';
// 导入基础样式和淡出效果样式
import 'swiper/css';
import 'swiper/css/effect-fade';

export default {
  components: { Swiper, SwiperSlide },
  setup() {
    return { EffectFade };
  },
};
</script>
```
