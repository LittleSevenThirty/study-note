### 使用流程

>1. 在想要的文件夹下，使用在命令行/终端打开，使用**git init**初始化一个**.git文件夹**和.gitignore文件
>2. 使用命令**git add .**将所有文件存入本地缓存区，或**git add 指定文件名**存入指定文件
>3. 使用命令**git commit  -m "填入提交的一些信息"**将缓存区文件存入本地仓库
>4. 使用命令**git config --global user.email "**自己项目的存放平台的邮箱" 和 **git config --global user.name "自己项目的存放平台的姓名"** 设置
>5. 使用命令 **git remote add origin https://gitcode.com/zql_littleSeven/group-buy-market-study.git**设置远程仓库的地址
>6. 使用命令 **git checkout -b 2-3-20250824-zql-multi-thread-study** 创建想要的分支，并切换到对应分支，使用命令 **git branch**可查看所有分支，**git checkout** 分支名称可以切换到对应分支，使用命令，-b后面是分支名称
>7. 使用命令 **git push -u origin 2-3-20250824-zql-multi-thread-study**将对应分支代码推送到远程仓库去基本成功了
