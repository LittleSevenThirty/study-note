# **pinia的使用**
这里优先记录组合式的写法

## **使用步骤**
**① 使用createPinia创建pinia实例并挂载**
这一步就相当于创建一个叫做pinia的大仓库，然后被app这个人使用
```ts
import { createApp } from "vue";
import { createPinia } from "pinia";

// 获取应用实例
const app=createApp(App);
const pinia=createPinia();

app.use(pinia);
```

**② 使用defineStore定义一个个的状态仓库**
任意store都必须要以`use`开头,`Store`结尾，定义一个个状态仓库相当于在上述创建的大仓库中再存放一个个箱子，存放一系列状态，行为
```ts
export const useCounterStore = defineStore('counter', () => {
  const count = ref(0)
  const name = ref('Eduardo')
  const doubleCount = computed(() => count.value * 2)
  function increment() {
    count.value++
  }

  // 必须步骤⭐
  return { count, name, doubleCount, increment }
})
```
在 Setup Store 中：

* `ref()` 就是 `state` 属性
* `computed()` 就是 `getters`
* `function()` 就是 `actions`
注意，要让 pinia 正确识别 state，**你必须在 setup store 中返回 state 的所有属性**。这意味着，你不能在 store 中使用私有属性。不完整返回会影响 SSR ，开发工具和其他插件的正常运行。

**③ 任意组件使用store**
`app.vue`
```js
<script setup lang="ts">
import useWebsiteStore from "./pinia/store/modules/website.ts";
import HelloWorld from "./components/HelloWorld.vue";
import { onMounted } from "vue";

const websiteStore=useWebsiteStore();

onMounted(()=>{
  websiteStore.getInfo();
})
</script>
```
