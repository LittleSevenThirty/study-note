# Java包 Lombok使用

## 注解：

### @AllArgsConstructor  

**作用：**  
生成一个包含所有字段的构造函数。  

**功能：**  
1. 自动生成一个参数顺序与类中字段声明顺序一致的构造函数。  
2. 若字段有 `final` 修饰，会强制生成带这些参数的构造函数。  

**示例：**  
```java
@AllArgsConstructor
public class User {
    private String name;
    private int age;
}

// 等效生成：
public User(String name, int age) {
    this.name = name;
    this.age = age;
}
```



### @Builder  

**作用：**  
为类生成一个链式构造器（Builder 模式），支持按需设置字段值。  

**功能：**  
1. 生成一个静态内部类 `Builder`。  
2. 提供链式方法设置字段（如 `.name("Alice").age(30)`）。  
3. 生成 `build()` 方法创建目标类实例。  

**示例：**  
```java
@Builder
public class User {
    private String name;
    private int age;
}

// 使用方式：
User user = User.builder().name("Alice").age(30).build();
```

---



### @Data  

**作用：**  
简化 POJO（Plain Old Java Object）类的代码，自动生成常用方法。  

**功能：**  
1. 自动生成所有字段的 `getter` 方法（非 `final` 字段生成 `setter`）。  
2. 生成 `equals()`、`hashCode()` 和 `toString()` 方法。  
3. 生成一个无参构造函数（若没有其他构造函数存在）。  

**示例：**  
```java
@Data
public class User {
    private String name;
    private int age;
}

// 等效的生成代码包含 getName(), setName(), equals(), hashCode(), toString() 等方法。
```

### @NoArgsConstructor  

**作用：**  
生成一个无参构造函数。  

**功能：**  
1. 生成一个无参数的默认构造函数。  
2. 若类中有 `final` 字段且未初始化，需要配合 `@Builder` 或手动处理。  

**示例：**  
```java
@NoArgsConstructor
public class User {
    private String name;
    private int age;
}

// 等效生成：
public User() {}
```

---

### 组合使用示例  
```java
@Data
@Builder
@AllArgsConstructor
@NoArgsConstructor
public class User {
    private String name;
    private int age;
}

// 组合后的功能：
// 1. 包含所有字段的构造函数（@AllArgsConstructor）
// 2. 无参构造函数（@NoArgsConstructor）
// 3. Builder 模式（@Builder）
// 4. 自动生成 getter/setter、equals()、hashCode()、toString()（@Data）
```

### @Setter

**作用：**

为类的成员属性生成Set方法

**功能：**

1. 用在类上就是为所有成员属性生成set方法
2. 用在单一成员属性上就是单独set方法

**参数：**

1. `value`
   设置setter方法的访问权限，支持`PUBLIC(默认)、PROTECTED、PACKAGE、PRIVATE`等
2. `onMethod`
   为生成的setter方法添加对应注解，常用于标记过时方法或添加校验逻辑
3. `onParam`
   为setter**方法的参数**添加注解（如@NonNull）用于参数非空校验

**示例：**

```java
@Setter(AccessLevel.PROTECTED)
private String name;  // 生成 protected 权限的 setName 方法
@Setter(onMethod = @__(@Deprecated))
private int age;  // 生成的 setAge 方法会被标记为 @Deprecated
@Setter(onParam = @__(@NonNull))
private String email;  // 若传入 null，编译时会抛出 NullPointerExceptio
```





## 注意事项  

1. **@Data 与构造函数注解的冲突**  
   - `@Data` 默认生成无参构造，但如果同时使用 `@AllArgsConstructor`，需显式添加 `@NoArgsConstructor`。  

2. **@Builder 与 @AllArgsConstructor**  
   - `@Builder` 默认依赖全参构造，若手动定义 `@AllArgsConstructor`，需确保其可见性为 `public` 或 `protected`。  

3. **字段顺序问题**  
   - `@AllArgsConstructor` 的参数顺序与类中字段声明顺序一致，需注意潜在错误。
