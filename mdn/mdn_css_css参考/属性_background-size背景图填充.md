# **background-size背景图填充**

### 1. 一句话核心总结
`background-size` 属性允许开发者灵活控制背景图片的尺寸，既可以精确设定宽高，也可以利用 `cover` 和 `contain` 关键词让图片智能地覆盖或适应容器，而无需担心图片变形。

### 2. 深度笔记内容

#### 📏 属性基础概览
*   **核心作用**：定义背景图片的尺寸。它可以保持图片原样，拉伸/压缩图片，或者在保持宽高比的前提下缩放图片以适应容器。
*   **初始值**：`auto auto`
*   **适用范围**：所有 HTML 元素（包括伪元素 `::first-letter` 和 `::first-line`）。
*   **继承性**：**否**（该属性不会被子元素继承）。
*   **动画支持**：支持，可以创建背景大小变化的动画效果。

#### 🛠️ 语法与值详解
该属性的值可以分为三大类：**关键字**、**具体数值**和**百分比**。

**A. 关键词（最常用的两个）**
这两个值主要用于在保持图片比例的前提下，解决“容器与图片尺寸不匹配”的问题：

*   **`cover`（覆盖）**
    *   **逻辑**：将背景图片**放大**到完全覆盖整个背景定位区域（容器）。
    *   **后果**：图片可能会被裁剪。图片会尽可能大，且保持宽高比，确保容器的每一个角落都被图片覆盖（通常图片的某一边会超出容器）。
    *   **场景**：全屏背景图、英雄区域（Hero Section）。

*   **`contain`（包含）**
    *   **逻辑**：将背景图片**缩小**（如果需要）以完全适应背景定位区域。
    *   **后果**：容器可能会留白。图片会尽可能大，且保持宽高比，确保图片完整显示在容器内（通常容器的某一边会有空白）。
    *   **场景**：需要完整展示 Logo 或图标，且不能变形的情况。

**B. 长度值与百分比**
*   **单位**：可以是具体的 `<length>`（如 `px`, `em`）或 `<percentage>`。
*   **百分比计算基准**：相对于**背景定位区域**（Background Positioning Area）的大小。这个区域通常由 `background-origin` 决定（默认是 padding-box，即包含内容区和内边距）。
*   **输入规则**：
    *   **一个值**：例如 `50%` 或 `200px`。这个值代表**宽度**，高度自动设置为 `auto`（保持比例）。
    *   **两个值**：例如 `50% 25%` 或 `200px 100px`。第一个是**宽度**，第二个是**高度**。

#### 🤔 计算逻辑与特殊情况
文档中详细解释了当值为 `auto` 或混合值时，浏览器如何计算最终尺寸。核心逻辑如下：

*   **有固有比例的图片**（大多数位图/矢量图）：
    *   如果只指定了宽或高，浏览器会根据图片的原始比例自动计算出另一个维度的值，防止图片被压扁。
*   **无固有比例的图片**（如某些渐变）：
    *   如果只指定一个值，另一个值通常会取背景定位区域的对应尺寸。
*   **混合值**（一个具体值 + `auto`）：
    *   优先使用指定的值，然后根据图片比例推算未指定的值。

> **💡 关键注意点**：文档特别提到，对于没有固有尺寸或比例的矢量图，旧版 Firefox（7及之前）和新版（8+）的处理方式不同。在现代开发中，虽然这种情况较少，但在维护老项目时需留意。

#### 🎨 视觉补充说明
*   **背景色的作用**：未被背景图片覆盖的区域（如使用 `contain` 时的留白，或图片透明时的底层），会显示由 `background-color` 设置的颜色。
*   **透明度影响**：如果背景图片是半透明的，底层的 `background-color` 会透出来，形成混合效果。

### 3. 关键启发/总结

从这篇文章中，我们可以提炼出以下核心开发逻辑：

1.  **`cover` vs `contain` 是响应式设计的基石**：
    *   记住口诀：**要全屏不留白用 `cover`，要完整不裁剪用 `contain`**。它们是处理不同分辨率屏幕下背景图适配的最佳方案。

2.  **`auto` 的智能性**：
    *   在设置背景图尺寸时，单值配合 `auto`（隐式或显式）是保持图片“不被压扁”的关键。除非有特殊设计需求，否则尽量避免两个都写死的数值，以免破坏图片比例。

3.  **背景定位区域的概念**：
    *   理解 `background-size` 的百分比是相对于谁（`background-origin`）计算的，对于精准布局非常重要。如果发现百分比尺寸不对，可能需要检查 `background-origin` 的设置。

4.  **渐进增强**：
    *   由于 `background-size` 在 2015 年后已广泛支持，现代开发中可以放心使用。但对于极老的浏览器兼容性要求（虽然现在极少），仍需留意文档中提到的历史版本差异。
