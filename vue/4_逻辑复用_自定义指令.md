

# Vue.js 自定义指令：轻松实现 DOM 操作

## 一、什么是自定义指令？

在 Vue.js 中，**指令（Directives）** 是以 `v-` 开头的特殊属性，用于在模板中添加特殊行为。Vue 内置了一些常用指令，比如 `v-model`（表单输入绑定）和 `v-show`（条件显示/隐藏）。

**自定义指令**就是让你自己创建新的指令，用于**直接操作 DOM 元素**。当你的需求无法通过 Vue 的内置指令或组件实现时，自定义指令就派上用场了。

> 📌 举个简单例子：想让输入框在页面加载后自动聚焦？用 `autofocus` 属性虽然可以，但只能在页面加载时生效。而自定义指令 `v-focus` 不仅在页面加载时有效，还能在 Vue 动态插入元素时也生效！

## 二、自定义指令的基本结构

自定义指令是一个**对象**，包含一系列钩子函数（类似组件的生命周期钩子）。这些钩子会在指令绑定到元素的不同阶段被调用。

### 1. 基本示例：添加高亮效果

```javascript
// 定义指令
const vHighlight = {
  mounted(el) {
    el.classList.add('is-highlight')
  }
}
```

```html
<p v-highlight>This sentence is important!</p>
```

当这个 `<p>` 元素被插入到页面时，会自动添加 `is-highlight` 类。

### 2. 常用的钩子函数

| 钩子函数 | 触发时机 |
|----------|----------|
| `created` | 元素被创建后（但还未插入 DOM） |
| `beforeMount` | 元素插入 DOM 前 |
| `mounted` | 元素插入 DOM 后（父组件和所有子节点都挂载完成） |
| `beforeUpdate` | 父组件更新前 |
| `updated` | 父组件和所有子节点更新后 |
| `beforeUnmount` | 父组件卸载前 |
| `unmounted` | 父组件卸载后 |

> 💡 提示：如果只需要在 `mounted` 和 `updated` 时执行相同逻辑，可以直接用函数定义，不用写完整对象。

## 三、如何注册自定义指令？

### 1. 局部注册（在组件内使用）

**使用 `<script setup>` 语法：**

```vue
<script setup>
// 以 v 开头的驼峰命名变量会自动作为指令
const vHighlight = {
  mounted(el) {
    el.classList.add('is-highlight')
  }
}
</script>

<template>
  <p v-highlight>This sentence is important!</p>
</template>
```

> 📌 重要：`vHighlight` 在模板中会以 `v-highlight` 形式使用（自动转为短横线命名）

**不使用 `<script setup>` 的传统写法：**

```vue
<script>
export default {
  directives: {
    // 在模板中启用 v-highlight
    highlight: {
      mounted(el) {
        el.classList.add('is-highlight')
      }
    }
  }
}
</script>
```

### 2. 全局注册（在所有组件中可用）

```javascript
import { createApp } from 'vue'

const app = createApp({})

// 全局注册 v-highlight 指令
app.directive('highlight', {
  mounted(el) {
    el.classList.add('is-highlight')
  }
})
```

## 四、指令的参数详解

指令的钩子函数会接收几个关键参数：

| 参数 | 说明 | 示例 |
|------|------|------|
| `el` | 指令绑定到的 DOM 元素 | `el.style.color = 'red'` |
| `binding` | 包含指令相关信息的对象 | `binding.value` 获取指令的值 |
| `vnode` | 代表绑定元素的底层 VNode | 用于高级场景 |
| `prevVnode` | 之前的 VNode（仅在 `beforeUpdate`/`updated` 中可用） | 用于比较变化 |

### 1. `binding` 对象的详细属性

| 属性 | 说明 | 示例 |
|------|------|------|
| `value` | 传递给指令的值 | `v-color="red"` 中的 `red` |
| `oldValue` | 之前的值（仅在 `beforeUpdate`/`updated` 中可用） | 上一次的值 |
| `arg` | 传递给指令的参数（`:` 后面的部分） | `v-example:foo` 中的 `foo` |
| `modifiers` | 修饰符对象 | `v-example.foo.bar` 中的 `{ foo: true, bar: true }` |

### 2. 实际使用示例

```html
<!-- 指令使用示例 -->
<div v-example:foo.bar="baz"></div>
```

在指令中，`binding` 会是：

```javascript
{
  arg: 'foo',                // 参数
  modifiers: { bar: true },  // 修饰符
  value: baz,                // 传递的值
  oldValue: oldBaz           // 之前的值（仅在更新时有）
}
```

## 五、指令的实用技巧

### 1. 简写形式（简单场景）

如果只需要在 `mounted` 和 `updated` 时执行相同逻辑，可以直接用函数：

```javascript
// 简写形式
app.directive('color', (el, binding) => {
  el.style.color = binding.value
})
```

```html
<!-- 使用 -->
<div v-color="red"></div>
```

### 2. 传递对象（多个值）

如果需要传递多个值，可以传递一个 JavaScript 对象：

```html
<div v-demo="{ color: 'white', text: 'hello!' }"></div>
```

```javascript
app.directive('demo', (el, binding) => {
  console.log(binding.value.color) // "white"
  console.log(binding.value.text)  // "hello!"
})
```

### 3. 动态参数

指令参数也可以是动态的：

```html
<div v-example:[arg]="value"></div>
```

这里 `arg` 会基于组件的 `arg` 数据属性响应式地更新。

## 六、重要注意事项

### 1. 不推荐在组件上使用自定义指令

当组件有多个根节点时，可能会出现意外行为：

```vue
<!-- MyComponent 的模板 -->
<template>
  <div>
    <!-- v-demo 指令会被应用在此处 -->
    <span>My component content</span>
  </div>
</template>
```

```html
<!-- 使用 -->
<MyComponent v-demo="test" />
```

> ⚠️ 注意：如果组件有多个根节点，指令会被忽略并抛出警告。

### 2. 优先使用 Vue 的内置指令

建议尽可能使用 `v-bind` 等内置指令，因为：
- 它们更高效
- 对服务端渲染更友好
- 代码更简洁

### 3. 何时使用自定义指令？

只有当**所需功能只能通过直接的 DOM 操作实现**时，才应该使用自定义指令。例如：
- 让元素自动获取焦点（`v-focus`）
- 实现复杂的 DOM 操作（如拖拽、滚动效果）
- 与第三方库集成（如高亮代码的库）

## 七、实战案例

### 案例 1：自动聚焦指令

```vue
<script setup>
const vFocus = {
  mounted(el) {
    el.focus()
  }
}
</script>

<template>
  <input v-focus placeholder="自动聚焦！" />
</template>
```

### 案例 2：动态颜色指令

```vue
<script setup>
const vColor = {
  mounted(el, binding) {
    el.style.color = binding.value
  },
  updated(el, binding) {
    el.style.color = binding.value
  }
}
</script>

<template>
  <p v-color="color">文字颜色会变化</p>
</template>
```

## 八、总结

自定义指令是 Vue.js 中用于**直接操作 DOM**的实用工具，特别适合那些无法通过 Vue 内置指令实现的功能。

**核心要点回顾：**
1. 自定义指令是对象，包含生命周期钩子函数
2. 常用钩子：`mounted`（插入 DOM 后）和 `updated`（更新后）
3. 通过 `binding.value` 获取指令的值
4. 优先使用简写形式（函数）处理简单场景
5. **不要过度使用**，优先考虑 Vue 的内置指令和组合式函数

> 📌 最后提醒：自定义指令不是万能的，它们应该用于**无法通过 Vue 响应式系统实现**的场景。当有更优雅的 Vue 方式（如组件或组合式函数）可以解决问题时，优先使用那些方式。
