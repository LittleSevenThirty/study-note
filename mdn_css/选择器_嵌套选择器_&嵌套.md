# 📘 CSS `&` 嵌套选择器 学习笔记

> ✅ 适用对象：已了解基础 CSS（如类选择器 `.class`、伪类 `:hover`），但未接触过 **CSS 嵌套语法** 的开发者。  
> ⏱️ 预计阅读时间：5–8 分钟

---

## 一、前置知识：什么是“嵌套”？

在传统 CSS 中，**不能直接在一个规则内部写另一个规则**：

```css
/* ❌ 传统 CSS 不允许这样写 */
.parent {
  color: red;
  .child {         /* 这会报错！ */
    color: blue;
  }
}
```

但在 **现代 CSS（2023 年起）** 和 **预处理器（如 Sass）** 中，**允许嵌套写法**，让代码更清晰：

```css
/* ✅ 现代 CSS 嵌套（需浏览器支持） */
.parent {
  color: red;
  .child {
    color: blue;
  }
}
```

浏览器会自动把它“展开”成：

```css
.parent {
  color: red;
}
.parent .child {
  color: blue;
}
```

> 🔍 关键点：**嵌套 = 把子选择器写在父选择器内部，表示“后代关系”**

---

## 二、问题来了：什么时候不需要空格？

有时我们**不想选后代元素**，而是想给**同一个元素**加不同状态，比如：

- `.button:hover`（鼠标悬停时的按钮）
- `.card.featured`（同时有 `card` 和 `featured` 类的元素）

如果直接嵌套：

```css
.card {
  background: white;
  .featured { /* ❌ 这会被理解为 .card .featured（后代）*/ }
}
```

但我们真正想要的是 **`.card.featured`（没有空格）**！

这时候就需要 `&`！

---

## 三、`&` 是什么？——“代表父选择器本身”

`&` 是一个**占位符**，代表**当前嵌套所在的父选择器**。

### ✅ 基本用法

```css
.parent {
  color: black;

  &:hover {
    color: red;
  }
}
```

等价于：

```css
.parent {
  color: black;
}
.parent:hover { /* 注意：没有空格！ */
  color: red;
}
```

> 💡 `&:hover` = “当父元素被悬停时”

---

## 四、常见使用场景

### 1. 伪类（`:hover`, `:focus`, `:active` 等）

```css
.button {
  padding: 8px;
  &:hover { background: lightblue; }
  &:focus { outline: 2px solid blue; }
}
```

→ 编译后：
```css
.button { padding: 8px; }
.button:hover { background: lightblue; }
.button:focus { outline: 2px solid blue; }
```

---

### 2. 组合类名（多个 class 在同一元素上）

```css
.card {
  border: 1px solid gray;
  &.featured { /* 注意：& 后直接接 .featured */
    border-color: gold;
    font-weight: bold;
  }
}
```

→ 编译后：
```css
.card { border: 1px solid gray; }
.card.featured { /* 没有空格！表示同一个元素 */
  border-color: gold;
  font-weight: bold;
}
```

---

### 3. 反向嵌套（把父选择器放在后面）

有时候你想写 `.theme-dark .card`，但你在 `.card` 里写：

```css
.card {
  color: black;
  .theme-dark & { /* & 放在最后 */
    color: white;
  }
}
```

→ 编译后：
```css
.card { color: black; }
.theme-dark .card { color: white; }
```

> ✨ 这叫“父选择器引用”，常用于主题切换、布局上下文等。

---

### 4. 多次使用 `&`

```css
.card {
  &.large & & { /* 相当于 .card.large .card .card */
    border: 2px solid red;
  }
}
```

（虽然少见，但语法支持）

---

## 五、对比：有 `&` vs 没有 `&`

| 写法 | 编译结果 | 含义 |
|------|--------|------|
| `.parent { .child {} }` | `.parent .child` | 选 `.parent` 内部的 `.child` 元素 |
| `.parent { &.active {} }` | `.parent.active` | 选同时有 `parent` 和 `active` 的元素 |
| `.parent { &:hover {} }` | `.parent:hover` | 选悬停状态下的 `.parent` |

> 🚫 没有 `&` → 自动加空格（后代选择器）  
> ✅ 有 `&` → 精确控制组合方式（无空格、前缀、后缀等）

---

## 六、注意事项

1. **浏览器支持**：  
   `&` 嵌套是 **CSS Nesting Module** 的一部分，**2023 年 12 月起**成为 Baseline 标准，主流浏览器（Chrome 119+、Firefox 121+、Safari 16.4+）已支持。

2. **不要和 Sass 混淆**：  
   Sass 早就支持 `&`，但**原生 CSS 的嵌套规则更严格**（例如必须用 `{}`，不能缩进）。

3. **根作用域中的 `&`**：  
   如果在最外层使用 `&`（不在任何嵌套内），它代表 `:scope`，通常指整个文档（`<html>` 或 `<body>`）：

   ```css
   &:hover { background: wheat; } /* 整个页面悬停变色（不推荐） */
   ```

---

## 七、总结速记卡（可直接背诵）

| 场景 | 写法 | 效果 |
|------|-----|------|
| 后代元素 | `.parent { .child {} }` | `.parent .child` |
| 同一元素加状态 | `.btn { &:hover {} }` | `.btn:hover` |
| 同一元素多 class | `.box { &.selected {} }` | `.box.selected` |
| 父上下文在前 | `.item { .dark & {} }` | `.dark .item` |

> ✅ 记住口诀：**“要连写，用 `&`；要后代，直接写。”**
