# CSS `line-height` 属性新手系统笔记

**核心作用一句话**：`line-height` 用来设置**文本行与行之间的垂直间距**（行高）。它不仅能让文字更好读，还是实现**垂直居中**的神器。

---

## 一、基础概念：什么是“行高”？

在写代码前，我们需要先看懂这个“高”到底指哪里。

- **基线**：想象一下英语练习本上的横线。在 CSS 中，字母（如 x, a）的底部是坐在**基线**上的。
- **行高**：两行文字**基线**之间的距离，就是 `line-height`。
- **行距**：行高减去文字本身的大小，剩下的空间就是行距。行距通常**平均分**在文字的上下两边（各占一半，也叫“半行距”）。
- **视觉效果**：如果行高太小，文字会挤在一起；如果行高太大，段落会显得松散。合适的行高（通常是字号的 1.5 倍左右）阅读体验最好。

---

## 二、语法结构

`line-height` 的语法非常灵活，它可以直接指定一个具体的数值或单位。

**CSS 语法格式**

```
选择器 {
  line-height: <值>;
}
```

---

## 三、值的 4 种设置方式（重点）

`line-height` 最让人困惑的地方在于它的值有 4 种写法，每种写法的计算规则和继承行为都不同。

**1. 无单位的数字 (推荐 )**

- **写法**：`1.5`、`2`、`1.2`
- **计算规则**：**当前元素的 **`font-size`** × 该数字**。
- **例子**：如果字体是 `16px`，`line-height: 1.5;`，那么行高就是 `16 * 1.5 = 24px`。
- **优点**：**最推荐使用**。因为它在继承时表现最好，子元素会根据自己的字号重新计算行高，不会导致小字变得太挤。

**2. 长度值 (px, em, rem)**

- **写法**：`24px`、`1.5em`
- **计算规则**：直接使用指定的值。
- **例子**：`line-height: 24px;` 就是固定 24 像素高。
- **注意**：
    - 使用 `px` 是固定的，不随字号变化。
    - 使用 `em` 时，它是相对于**当前元素**的 `font-size` 计算的（例如 `font-size: 16px; line-height: 1.5em;` 结果也是 `24px`）。

**3. 百分比 (%)**

- **写法**：`150%`
- **计算规则**：**当前元素的 **`font-size`** × 百分比**。
- **例子**：`font-size: 16px; line-height: 150%;` 结果也是 `24px`。
- **注意**：虽然计算结果和 `1.5` 一样，但在**继承**时会有很大区别（后面会讲）。

**4. 关键字**

- `normal`：浏览器的默认行高。通常在 `1.0` 到 `1.2` 之间，具体取决于字体和浏览器。如果你不做特殊要求，用这个就行。
- `inherit`：继承父元素的 `line-height` 值。

---

## 四、新手必懂的“继承”陷阱

`line-height` 是可继承的，但不同写法在继承时的表现截然不同。这是面试常考点，也是新手容易写错的地方。

假设父元素设置了 `line-height`，子元素没有设置，但有自己的 `font-size`。

- **情况 A：父元素使用 **`数字`** (如 1.5)**
    - **行为**：子元素继承的是**数字 **`1.5`。
    - **结果**：子元素会用自己的字号 × 1.5 来计算行高。
    - **评价**：**完美**。大标题和小正文都能保持舒适的行间距。
- **情况 B：父元素使用 **`px`** (如 24px)**
    - **行为**：子元素继承的是**固定的 **`24px`。
    - **结果**：如果子元素的字号很小（比如 `12px`），24px 的行高可能刚好；但如果子元素字号很大（比如 `30px`），24px 的行高就不够用了，文字会重叠！
    - **评价**：**不灵活**。
- **情况 C：父元素使用 **`%`** (如 150%)**
    - **行为**：浏览器先计算出父元素的行高值（比如 `16px * 150% = 24px`），然后把这个**计算后的像素值 **`24px` 传给子元素。
    - **结果**：和 `px` 一样，子元素拿到的是一个死板的数字，不会随自己的字号缩放。
    - **评价**：**容易出错，慎用**。

**结论**：为了排版的健壮性，**强烈建议使用“无单位的数字”**（如 `1.5`）。

## 五、实战应用场景

**1. 设置舒适的段落阅读间距**

```
p {
  font-size: 16px;
  line-height: 1.6; /* 推荐 1.5 - 1.8 之间，阅读不累眼 */
}
```

**2. 让单行文字垂直居中 (经典技巧)**

- **原理**：把 `line-height` 的值设置成和容器 `height` 一样高。
- **代码**：

```
.button {
  height: 40px;
  line-height: 40px; /* 行高等于高，文字就会被“夹”在中间 */
  text-align: center; /* 配合这个，水平居中 */
}
```

- **注意**：这招只对**单行**文字有效。

**3. 全局重置 (CSS Reset)**

- 很多 CSS 框架会在最开始写一句，统一所有浏览器的默认行高：

```
body {
  line-height: 1.5; /* 统一设置为 1.5 倍，去掉浏览器默认的差异 */
}
```

---

## 六、总结与避坑指南

- **首选数字**：永远优先使用 `line-height: 1.5;` 这种无单位数字写法，它最安全、最灵活。
- **不要用负值**：`line-height` 不允许是负数。
- **区分 **`em`** 和数字**：
    - `line-height: 1.2;`（推荐，基于自身字号计算）。
    - `line-height: 1.2em;`（不推荐，虽然结果一样，但在某些嵌套场景下计算逻辑更复杂）。
- **多行居中**：`line-height` 只能搞定单行居中。如果是多行文字要垂直居中，需要用 `flexbox` 布局或者 `table-cell` 技巧（这是进阶内容，以后再学）。
