# 滑动窗口最大值

### 自己理解

#### 题目描述

> 给你一个整数数组 `nums`，有一个大小为 `k` 的滑动窗口从数组的最左侧移动到数组的最右侧。你只可以看到在滑动窗口内的 `k` 个数字。滑动窗口每次只向右移动一位。
>
> 返回 *滑动窗口中的最大值* 。
>
>  
>
> **示例 1：**
>
> **输入：**nums = [1,3,-1,-3,5,3,6,7], k = 3 **输出：**[3,3,5,5,6,7] **解释：** 滑动窗口的位置                最大值 ---------------               ----- [1  3  -1] -3  5  3  6  7       **3** 1 [3  -1  -3] 5  3  6  7       **3** 1  3 [-1  -3  5] 3  6  7       **5** 1  3  -1 [-3  5  3] 6  7       **5** 1  3  -1  -3 [5  3  6] 7       **6** 1  3  -1  -3  5 [3  6  7]      **7**

#### 解题思路

暴力解法的解题时间是n*k，n是数组的长度，k是滑动窗口的最大值

**注意，这个需要双端出元素**

而我们把窗口滑动进入元素，出元素看做成队列，即从右边入队列，从左边出队列，而我们需要维系的就是这个队列中保留可能是最大元素值的元素，那么怎么实现呢？首先需要保证队列的长度和窗口的长度一致，即k=size，我们每进入一个元素，①判断当前队列中元素是否达到k值；②判断当前队列顶元素是否小于当前入队列值，如果小于，那么就弹出，直到当前队列顶元素大于或等于入队列值；

为什么不用继续维护被弹出值，①弹出值要么不是当前窗口中最大值，要么是该被弹出值在数组中超出窗口范围了

#### 代码

>class Solution {
>
>​    public int[] maxSlidingWindow(int[] nums, int k) {
>
>​        if(nums.length == 0 || k == 0) return new int[0];
>
>​        Deque<Integer> deque = new LinkedList<>();
>
>​        int[] res = new int[nums.length - k + 1];
>
>​        for(int j = 0, i = 1 - k; j < nums.length; i++, j++) {
>
>​            // 删除 deque 中对应的 nums[i-1]
>
>​            if(i > 0 && deque.peekFirst() == nums[i - 1])
>
>​                deque.removeFirst();
>
>​            // 保持 deque 递减
>
>​            while(!deque.isEmpty() && deque.peekLast() < nums[j])
>
>​                deque.removeLast();
>
>​            deque.addLast(nums[j]);
>
>​            // 记录窗口最大值
>
>​            if(i >= 0)
>
>​                res[i] = deque.peekFirst();
>
>​        }
>
>​        return res;
>
>​    }
>
>}
