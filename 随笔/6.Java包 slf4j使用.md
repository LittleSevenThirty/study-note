# java包 slf4j使用

### 创建一个日志

* **作用：**
  在代码中声明日志记录器，用于记录应用程序运行时的状态、错误、调试信息等，便于后期监控、问题排查和系统维护
* **功能：**
  通过 `LoggerFactory.getLogger()` 方法获取与当前类绑定的日志记录器实例，自动关联类名作为日志标识，支持不同日志级别（如 DEBUG、INFO、ERROR）的输出，并可通过配置文件（如 logback.xml）控制日志格式、输出目标和过滤规则。

* **示例：**

  ```java
  private Logger logger = LoggerFactory.getLogger(this.getClass());
  ```



### @Slf4j 注解

- ‌**作用：**‌
  通过 Lombok 注解自动生成日志记录器变量，简化手动声明日志对象的代码，提升代码简洁性和可维护性。

- ‌**功能：**‌
  在编译时自动注入名为 `log` 的静态日志实例（基于 SLF4J），隐式关联当前类名，无需手动调用 `LoggerFactory.getLogger()`。支持直接通过 `log.debug()`、`log.info()` 等方法记录日志，与手动声明日志记录器功能完全一致。

- ‌**示例：**‌
  ```java
  @Slf4j
  public class MyService {
      public void doSomething() {
          log.info("业务逻辑执行中..."); // 直接使用 log 对象
      }
  }
  ```

* **补充：**
  上述代码会被编译成

  ```java
  public class MyService {
      private static final 
           org.slf4j.Logger log=org.slf4j.LoggerFactory.getLogger(ExampleClass.class);
      
      public void doSomething() {
          log.info("业务逻辑执行中..."); // 直接使用 log 对象
      }
  }
  ```
