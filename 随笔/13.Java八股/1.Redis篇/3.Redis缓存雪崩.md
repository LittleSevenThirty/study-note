# Redis缓存雪崩

## 自己理解

当Redis的大部分Key值失效或者Redis掉线都有可能导致出现缓存雪崩，出现大部分Key值失效的情况一般都是设置了相同Key值的生效时间，所以解决呢，就是设置不同的生效时间，避免同时失效，而Redis掉线的解决就是布置集群，或者添加降级缓存？
