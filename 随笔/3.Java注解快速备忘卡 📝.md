# Java注解快速备忘卡 📝

## 一、注解的本质
- &zwnj;**特殊接口**&zwnj;：用`@interface`定义，编译后生成接口（不是普通类！）
- &zwnj;**元数据工具**&zwnj;：给代码打标签（如`@Override`），用于携带配置信息

## 二、注解元素（看着像方法，实际是属性！）
```java
public @interface MyAnnotation {
    // 元素 = 抽象方法的形式
    String value() default "";    // ✔️ 这是属性，不是真方法！
    int priority() default 0;     // 默认值用default设置
}
```



## 三、关键元注解（控制注解行为的注解）

| 元注解        | 作用                   | 示例值                  |
| ------------- | ---------------------- | ----------------------- |
| `@Retention`  | 控制注解存活时间       | RetentionPolicy.RUNTIME |
| `@Target`     | 指定注解能用在哪些地方 | ElementType.METHOD      |
| `@Documented` | 是否出现在JavaDoc中    | 无参数                  |
| `@Inherited`  | 是否被子类继承         | 无参数                  |

## 四、反射读取三步法 🕶️

1. ‌**获取注解实例**‌：

```java
Method method = MyClass.class.getMethod("MyClass的方法名称");
MyAnnotation myAnnotation = method.getAnnotation(MyAnnotation.class);
```

1. ‌**读取元素值**‌（像调用接口方法）：

   ```java
   String value = anno.value();  // 调用"方法"获取实际值
   int priority = anno.priority();
   ```

2. ‌**必须配置**‌：

   ```java
   @Retention(RetentionPolicy.RUNTIME) // 必须！否则反射读不到
   ```

## 五、使用场景速记

- 框架配置（如Spring的`@Autowired`）
- ORM映射（如MyBatis的`@Select("SQL")`）
- 代码检查（如`@Override`）
- 生成文档（如Swagger注解）

## 六、常见坑点 ⚠️

1. 忘记设置`@Retention(RetentionPolicy.RUNTIME)`

2. 试图给没有默认值的元素不赋值：

   ```java
   @BadAnnotation // 编译报错！缺少必须元素
   ```

3. 混淆

   ```java
   value()
   ```

   特殊规则：

   ```java
   @GoodAnnotation("可以直接写值") // 等价于@GoodAnnotation(value="...")
   ```

## 七、形象比喻

- 注解 ≈ 便利贴（贴在代码上的小纸条）
- 反射 ≈ 显微镜（读取这些纸条内容）
- 元注解 ≈ 便利贴的使用说明（比如：贴在哪个位置、多久会掉）
