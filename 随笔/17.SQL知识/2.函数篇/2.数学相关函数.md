# 数学相关函数

## 自己理解

### round函数

**解释：**根据指定的小数位数，将数字进行保留的四舍五入

**语法：**

>round(number,decimals)

**参数：**

* number：要被四舍五入的数字
* decimals：填入整数，会对number保留decimals+1位数字

**示例：**

```sql
select round(1.234,0)	// 结果为1
select round(123,-1)	// 结果为120
```



#### truncate函数

**解释：**根据指定小数位数，只保留指定小数位数，其余砍掉，不进行四舍五入

**语法：**

>truncate(number,decimals)

**参数：**

* number：要被截断的数字
* decimals：填入整数，会对number保留decimals+1位数字

**示例：**

```sql
select truncate(1.234,1)	// 结果为1.2
select truncate(123,-1)	// 结果为120
```
