# 5. String类理解

## 自己理解



## 已用方法

### 1.substring方法

**作用：**从当前字符串中截取一截子串，就像=》剪刀剪一段绳子

**基本用法：**

```java
String str="hello world";

String subStr1=str.subString(5);	// subStr1=" world"

String subStr2=str.subString(0,4);	// subStr2="hell"
```

**规则：**

- 字符串索引从 0 开始（第一个字符是索引 0）
- `substring(start)`：从 start 到末尾
- `substring(start, end)`：从 start 到 end-1（左闭右开）



### 2. indexOf方法

**作用：**找到某个字符或字符串在当前字符串首次出现的位置

**基本用法：**

```java
String str = "I love Java, Java is great!";

// 找单个字符
int index1 = str.indexOf('J');  // 输出7（第一个J的位置）

// 找子字符串
int index2 = str.indexOf("Java");  // 输出7

// 从指定位置开始找
int index3 = str.indexOf("Java", 8);  // 输出17（第二个Java的位置）

// 没找到返回-1
int index4 = str.indexOf("Python");  // 输出-1
```

**规则：**

* indexOf("字符/字符串",查找位置)：默认查找位置从0开始

**tips：**

* 反向查找用lastIndexOf



### 3. split方法

**作用：**根据某个字符将当前字符串分割成一段一段的

**基本用法：**

```java
String str = "apple,banana,orange";

// 按逗号分割
String[] fruits = str.split(",");
// fruits数组：["apple", "banana", "orange"]

// 按空格分割（多个空格当一个处理）
String text = "Hello   world!";
String[] words = text.split(" ");
// words数组：["Hello", "world!"]
```

**规则：**

* 根据指定字符，以及后续参数limit分割limit次数的字符子串



### 4.trim方法

**作用**：删掉字符串开头和结尾的空格，中间的空格保留～

**1. 基本用法：**

```java
String str1 = "  hello  ";
String str2 = str1.trim();  // str2是"hello"

String str3 = "  hi  there  ";
String str4 = str3.trim();  // str4是"hi  there"（中间空格保留）
```

**2. 注意事项：**

- 只删**空格**（' '），不删制表符（'\t'）、换行符（'\n'）等
- 想删其他空白字符，用正则：

```java
String str = "\t  abc  \n";
String cleaned = str.replaceAll("\\s+", "");  // 删掉所有空白字符
```



### 5.equals方法

**作用：**比对当前字符串和传入字符串值是否相等

**基本用法：**

```java
String str1="aabbcc";
String str2="aabbbc";
String str3="aabbcc";

str1.equals(str2);	// false
str1.equals(str3);	// true
```

**规则：**
传入字符串，进行比对
