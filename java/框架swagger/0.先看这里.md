# **swagger是什么？**
## 一、背景：什么是 Swagger？它在技术生态中的角色？

- **Swagger** 是一套围绕 **OpenAPI 规范**（原称 Swagger 规范）构建的开源工具集。
- **OpenAPI 规范** 是一种用于描述 RESTful API 的标准化格式（通常以 YAML 或 JSON 表示），使得：
  - 前端开发者能清楚知道后端接口的请求/响应结构；
  - 测试人员可自动生成测试用例；
  - 文档可自动同步更新；
  - 客户端 SDK 可自动生成。
- **Swagger 生态常见组件**：
  - **Swagger UI**：将 OpenAPI 文档渲染为交互式 Web 页面；
  - **Swagger Core / Springdoc OpenAPI**：在 Java 项目中通过注解生成 OpenAPI 文档；
  - **Swagger Codegen**：根据 OpenAPI 文档生成客户端或服务端代码。

> 💡 在 Java Spring Boot 项目中，常用 `springdoc-openapi`（基于 Swagger）来自动生成 API 文档。
