# **入门解读**🛋️
本篇是对于vue-router官方文档入门篇的解读，让新手更容易掌握如何在vue中使用路由。本篇续用文档的说法`Router或router`**以er为尾的才叫路由**

>客户端路由的作用是在单页应用 (SPA) 中将浏览器的 URL 和用户看到的内容绑定起来。当用户在应用中浏览不同页面时，URL 会随之更新，但页面不需要从服务器重新加载。
>Vue Router 基于 Vue 的组件系统构建，你可以通过配置路由来告诉 Vue Router 为每个 URL 路径显示哪些组件。

**示例解读**
```js
<template>
  <h1>Hello App!</h1>
  <p><strong>Current route path:</strong> {{ $route.fullPath }}</p>
  <nav>
    <RouterLink to="/">Go to Home</RouterLink>
    <RouterLink to="/about">Go to About</RouterLink>
  </nav>
  <main>
    <RouterView />
  </main>
</template>
```
**关键词**：`$route.fullPath`,`<RouterLink to=""></RouterLink>`,`<RouterView/>` Vue Router主要围绕这3者讲的，只要将类似知识和这三者进行等价替换就好学了

## **路由实例的创建和挂载**
**示例**
```js
// 部分1：导入对应函数组件，其中createRouter是必须的
import { createMemoryHistory, createRouter } from 'vue-router'

import HomeView from './HomeView.vue'
import AboutView from './AboutView.vue'

// 部分2：定义路由映射，将 URL 路径和组件进行映射
const routes = [
  { path: '/', component: HomeView },
  { path: '/about', component: AboutView },
]

// 部分3：使用函数创建路由实例
const router = createRouter({
  history: createMemoryHistory(),
  routes,
})

// ==============================================================
// ...
// 到主文件中main.ts中挂载路由实例，或者说让vue使用插件
import {createApp} from 'vue';
createApp(App).use(router).mount("#app");
```
>&nbsp;&nbsp;&nbsp;&nbsp;这里的 routes 选项定义了一组路由，把 URL 路径映射到组件。其中，由 component 参数指定的组件就是先前在 App.vue 中被 <RouterView> 渲染的组件。这些路由组件通常被称为视图，但本质上它们只是普通的 Vue 组件。
>&nbsp;&nbsp;&nbsp;&nbsp;其他可以设置的路由选项我们会在之后介绍，目前我们只需要 path 和 component。
>&nbsp;&nbsp;&nbsp;&nbsp;这里的 history 选项控制了路由和 URL 路径是如何双向映射的。在演练场的示例里，我们使用了 createMemoryHistory()，它会完全忽略浏览器的 URL 而使用其自己内部的 URL。

>和大多数的 Vue 插件一样，use() 需要在 mount() 之前调用。
>如果你好奇这个插件做了什么，它的职责包括：
>1.全局注册` RouterView` 和 `RouterLink `组件。
2.添加全局 `$router` 和 `$route` 属性。
3.启用 `useRouter() `和` useRoute()` 组合式函数。
4.触发路由器解析初始路由。

## **访问路由器和当前路由**
在组件模板中，路由器实例将被暴露为 `$router`。这与同样被暴露的 `$route` 一样，但注意前者最后有一个额外的`r`，在`选项式API`中可以使用`this.$router`或`this.$route`进行访问，两者前者是用来**“去哪”**，后者是用来 **“我在哪”**
对于`选项式API`我们不能通过 `this` 访问组件实例，所以 Vue Router 给我们提供了一些组合式函数`useRouter`和`useRoute`函数获取`router`和`route`实例等价于`$router`和`$route`
