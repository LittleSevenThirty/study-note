# **attr获取HTML元素上的属性**

### attr()

**【原文要点】**
`attr()` 是一个 CSS 函数，它的核心作用是**“偷看”** HTML 元素的属性值，并把这个值“拿”过来用在 CSS 样式里。它最早在 2015 年就被广泛支持了，是一个非常成熟的功能。虽然它可以和任何 CSS 属性一起用，但目前除了 `content` 属性外，其他属性的使用还处于“实验性”阶段。

**【深度拆解】**
想象一下，CSS 通常是独立于 HTML 的，CSS 不知道 HTML 标签里写了什么属性。`attr()` 就像一个翻译官，它能读取 HTML 标签（比如 `<p data-name="hello">`）里的 `data-name` 的值 `hello`，然后告诉 CSS：“嘿，把这个 `hello` 当作内容显示出来”。

---

### 语法

**【原文要点】**
`attr()` 的语法非常灵活，基本结构如下：
```css
attr(<attr-name> <attr-type>?, <fallback-value>?)
```

**【深度拆解】**
我们可以把这个函数想象成一个“取快递”的指令，它有三个参数：

1.  **`<attr-name>` (要取什么)**：这是必填项。你要告诉浏览器去 HTML 标签里找哪个属性的名字。比如 `data-foo`。
2.  **`<attr-type>` (怎么理解它)**：这是选填项。告诉浏览器拿到这个属性的值后，是把它当“文字”看，还是当“数字”看，或者是带单位的“长度”。
    *   **`raw-string`**：最原始的字符串。原封不动地拿过来，不做任何处理。
    *   **`type()`**：指定数据类型，比如 `type(number)`。
    *   **`<attr-unit>`**：指定单位，比如 `px`（像素）、`deg`（角度）、`%`（百分比）。
3.  **`<fallback-value>` (如果找不到怎么办)**：这也是选填项。如果 HTML 标签里没有那个属性，或者属性值是无效的，就用这个备用值。

---

### 解释

**【原文要点】**
这一部分详细解释了 `attr()` 的返回值逻辑以及它的一些限制和向后兼容性问题。

**【深度拆解】**

*   **返回值逻辑**：
    *   如果你指定了 `<attr-type>`（比如 `px`），浏览器会尝试把属性值转换成那种类型。如果转换失败（比如属性里写的是“红色”却要转成数字），就会返回备用值（`<fallback-value>`）。
    *   如果你没指定 `<attr-type>`，属性值默认会被当作字符串处理。
    *   如果你什么都没设置，属性又不存在，默认返回空字符串。

*   **限制与安全性（非常重要！）**：
    *   **不能用于 URL**：出于安全考虑，你**绝对不能**用 `attr()` 来拼接 URL（比如背景图片地址）。因为 HTML 属性里可能包含敏感信息（像安全令牌），如果通过 CSS 暴露给 URL，可能会被黑客利用。
    *   **“被污染的”值**：浏览器会标记 `attr()` 拿到的值是“被污染的”。如果你试图在 `url()` 里用这个值，浏览器会直接报错（IACVT），防止信息泄露。

*   **向后兼容性（坑点预警）**：
    *   旧版浏览器（不支持新语法的）和新版浏览器处理 `attr()` 的方式不一样。
    *   **坑 1**：如果你写了现代语法（带类型），旧浏览器看不懂会直接丢弃这条规则，导致显示旧效果；新浏览器看懂了但发现值无效，可能会显示为空。
    *   **坑 2**：如果父元素没有属性，子元素继承了 `attr()`，旧浏览器会显示属性名，新浏览器会显示为空。

---

### 特性检测

**【原文要点】**
为了防止上面提到的兼容性问题，建议使用 `@supports` 规则或 JavaScript 的 `CSS.supports()` 来检测浏览器是否支持现代的 `attr()` 语法。

**【深度拆解】**
这就像是在进门前先敲门确认一下：“你支持这种新式装修风格吗？”
*   **CSS 检测**：使用 `@supports`，尝试给一个非自定义属性赋一个高级的 `attr()` 值。如果支持，就应用一套样式；如果不支持，就应用另一套保底样式。
*   **JS 检测**：用 `CSS.supports()` 函数进行同样的逻辑判断。

### 语法格式

**【原文要点】**
这是非常硬核的技术定义，展示了 `attr()` 在 CSS 语法规范中的精确写法。

**【深度拆解】**
这部分内容主要面向规范制定者，但作为学习者，你只需要知道它定义了 `attr()` 可以接受的各种参数组合，包括：
*   `<attr-name>`：属性名。
*   `<attr-type>`：可以是 `type()` 函数、`raw-string` 关键字，或者具体的单位（如 `number`, `px` 等）。
*   `<syntax>`：定义了类型的具体语法结构（如 `*` 代表任意，或者具体的类型名如 `color`, `length`）。

### 示例

**【原文要点】**
文档提供了多个代码示例，展示了 `attr()` 在不同场景下的用法。

**【实例教学】**

#### 1. content 属性（最经典用法）

**代码块：**
```html
<p data-foo="hello">世界</p>
```
```css
p::before {
  content: "你好 " attr(data-foo);
}
```

*   **逐行拆解**：
    *   HTML：创建了一个段落，里面有一个自定义属性 `data-foo`，值是 `hello`。
    *   CSS：`p::before` 是在段落前面插入内容。
    *   `content`：内容是固定的字符串“你好 ”，然后加上 `attr(data-foo)`。
*   **视觉效果**：页面上会显示 **“你好 hello 世界”**。CSS 成功读取了 HTML 的属性值。

---

#### 2. 使用回退值（备用方案）

**代码块：**
```html
<p data-browser="Chrome">是一个浏览器。</p>
<p>也是一个浏览器。</p>
```
```css
p::after {
  content: " (" attr(data-browser, string, "未知") ")";
}
```

*   **逐行拆解**：
    *   第一个 `<p>` 有 `data-browser` 属性，值是 `Chrome`。
    *   第二个 `<p>` 没有这个属性。
    *   CSS：`attr(data-browser, string, "未知")` 的意思是：找 `data-browser` 属性，把它当字符串处理，如果找不到，就显示“未知”。
*   **视觉效果**：
    *   第一行显示：**“是一个浏览器。 (Chrome)”**
    *   第二行显示：**“也是一个浏览器。 (未知)”**。因为没有属性，所以触发了回退值“未知”。

---

#### 3. 使用颜色值（实验性）

**代码块：**
```html
<div data-background="red"></div>
<div data-background="invalid-color"></div>
```
```css
div {
  width: 100px;
  height: 100px;
  background-color: attr(data-background color, gray);
}
```

*   **逐行拆解**：
    *   `attr(data-background color, gray)`：尝试读取 `data-background`，并强制把它解析为**颜色**类型。如果解析失败（比如值不是合法颜色），就用备用色 `gray`（灰色）。
*   **视觉效果**：
    *   第一个方块是**红色**（因为 `red` 是合法颜色）。
    *   第二个方块是**灰色**（因为 `invalid-color` 不是合法颜色，触发了回退值 `gray`）。

---

#### 4. 使用尺寸单位（实验性）

**代码块：**
```html
<div data-rotation="45"></div>
<div data-rotation="abc"></div>
```
```css
div {
  transform: rotate(attr(data-rotation deg, 0deg));
}
```

*   **逐行拆解**：
    *   `attr(data-rotation deg, 0deg)`：读取 `data-rotation` 的值，并假设它是**度数（deg）**。如果值无效，就旋转 `0deg`（不旋转）。
*   **视觉效果**：
    *   第一个方块会**旋转 45 度**。
    *   第二个方块**保持原位**（因为 `abc` 无法转成度数，触发了 `0deg`）。

---

#### 5. 将 attr() 值解析为 （高级用法）

这个例子结合了 CSS 视图过渡（View Transitions），稍微复杂一点。

**代码块：**
```html
<div class="card" id="card-1"></div>
<div class="card" id="card-2"></div>
<button>打乱顺序</button>
```
```css
.card {
  view-transition-name: attr(id custom-ident, none);
}
```

*   **逐行拆解**：
    *   `view-transition-name` 是一个用于控制页面切换动画的属性，它需要一个标识符（ident）。
    *   `attr(id custom-ident, none)`：读取元素的 `id` 属性（如 `card-1`），并把它解析为一个**自定义标识符**。如果元素没有 `id`，就用 `none`（不启用过渡）。
*   **视觉效果**：当点击按钮打乱卡片顺序时，浏览器知道每张卡片的动画名字是 `card-1`、`card-2`，从而能平滑地移动卡片位置，而不是生硬地跳动。

### 规范

**【原文要点】**
`attr()` 函数的定义位于 **CSS Values and Units Module Level 5** 规范中。

**【深度拆解】**
这意味着 `attr()` 是 CSS 标准化进程中的一部分。虽然目前很多用法（除了 content）还在 Level 5 中定义，属于较新的特性，但随着浏览器更新，这些功能会越来越普及。

---

### 浏览器兼容性

**【原文要点】**
*   **基础支持**：所有现代浏览器都支持 `attr()` 用于 `content` 属性。
*   **高级支持**：对于其他 CSS 属性（如 color, length），支持程度是实验性的，需要查看具体的兼容性表格。

**【易错提醒/注意】**
*   **不要在生产环境滥用**：除了 `content` 之外，其他属性的 `attr()` 支持可能不稳定。
*   **安全红线**：永远不要试图用 `attr()` 去加载图片或外部资源（`url()`），这是被浏览器禁止的。
*   **兼容性处理**：在使用现代语法（带类型和单位的）时，务必考虑旧浏览器的降级方案，或者使用特性检测（`@supports`）来包裹代码。
